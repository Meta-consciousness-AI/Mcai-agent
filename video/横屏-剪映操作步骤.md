# 横屏视频：剪映操作步骤

> 一次只做一步，每步完成后确认，再进入下一步。
> 素材目录：`video/horizontal/`
> 分镜与口播：`video/horizontal/分镜.md`

## 步骤清单

- [ ] **1. 新建项目**：16:9，1920×1080，30fps
- [ ] **2. 导入图片**：按 `slide-01.png` → `slide-14.png` 顺序拖入主轨
- [ ] **3. 初始时长**：每张图先统一设为 3 秒（后续按音频拉长）
- [ ] **4. 第 1 页配音**：粘贴开场段，文本朗读，语速 1.0
- [ ] **5. 第 1 页对齐**：图片时长 = 该段音频长度
- [ ] **6. 第 2–14 页**：逐页重复 4–5 步
- [ ] **7. 语速检查**：听第 1、4 页，赶就把该段调到 0.9
- [ ] **8. 总时长检查**：应在 190–210 秒之间
- [ ] **9. 字幕**：自动识别后逐页校对（见素抱朴、mcprush、0.3.2）
- [ ] **10. 配乐**：音量 10–15%，不盖过人声
- [ ] **11. 导出**：1080P，30fps
- [ ] **12. 发布**：腾讯视频、爱奇艺；视频号可同步横屏版

## 每页口播对应

分镜表第 1–14 行，一页一段，直接复制粘贴。
