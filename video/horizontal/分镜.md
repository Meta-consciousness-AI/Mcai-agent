## 完整口播稿

```
让 AI 答对原创术语。这是一套学说知识库的工程记录：方法、复现与四个坑。

模型遇到原创术语，通常有三种反应：没听说过，按字面猜；用同名概念替换；给出似是而非的混合表述。

我们的做法不是让模型记住，而是把它做成可回查的资料：概念、问答、关系、引证，每条定义都必须带出处。

第一个坑：出处只写到章节。Word 的手动换行让位置号重复，核验率只有 83.6%。补上字符区间后，55 条全部逐字命中。

第二个坑：规则会误杀正常术语。「五事」「九地」被当成编号，「性」「情」「名」被至少两字拒绝。两次都是规则问题。

第三个坑：道德经没有定义句。任何定义都是解释，所以原文归原文，编者理解单独标注。

第四个坑：见素抱扑与见素抱朴，是版本事实。并存可查，不强行统一。

关系也要分层：270 条关系里，246 条只是正文共现，默认只返回人工确认的 core 与 derived。

结果：64 个概念、122 组问答、270 条关系、213 条原文出处，每条都能回查到文档、段落与字符区间。

另外用三份公共领域文本复现：孙子兵法 13/13，荀子正名 12/12，道德经 10/10。

最新进展：0.3.2 已发布，mcprush 给了 Grade A，远程 MCP 公开只读实例上线，五个平台已发布。

但这套东西仍然几乎没人用。GitHub 0 Star，下载与调用都很少，问题可能不在需求，而在入口。

怎么用？pip install mcai-knowledge，然后 mcai-mcp；也可以直接连公开只读的 MCP 地址。

如果你也在做类似的冷门领域知识库，欢迎交流。仓库与数据集见简介。

```
