# 审校标准（问答与关系，2026-11-20）

> 用途：逐条审校 122 条问答、270 条关系；每条给出保留 / 修正 / 待定。

## 一、六条硬标准

| # | 标准 | 反例 |
|---|---|---|
| S1 | 只用知识库已有术语，不新造术语 | 「节拍面」 |
| S2 | 不把结构面/条件说成「元实体」 | 「空间的元实体」 |
| S3 | 区分元时空与现象时空；空间不等于现象时空整体 | 「空间（现象时空）」 |
| S4 | 显化必须经观测/测创，不写自动显化 | 「尺度面自动变成空间」 |
| S5 | 用现象语汇指称本体时，必须加限定 | 「序生场是物理场」 |
| S6 | 模型表述不写成物理断言，不引入未定义结论 | 「时间就是量子涨落」 |
