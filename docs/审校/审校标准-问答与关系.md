# 审校标准（问答与关系，v2）

> 日期：2026-11-20
> 来源：从新问答「空间和时间是元实体吗？」提炼**通用**标准，而不是把该问答的领域结论当成所有条目的尺子。
> 原则：只改「不清楚、越界、逻辑跳步、无出处」的少数；已表述清晰、逻辑严密的，保留。

## 一、七条通用标准

| # | 标准 | 说明 | 反例 |
|---|---|---|---|
| U1 | 术语纪律 | 只用知识库已有术语；不造新词、不造同义替代；确需新词，先立条目再使用 | 「节拍面」 |
| U2 | 范畴纪律 | 按术语所属层级使用：本体、结构面、实体、关系、制度，不把 A 类对象说成 B 类；跨体系引用须标明语境 | 把结构面说成「元实体」 |
| U3 | 差异纪律 | 相邻或易混术语，必须能说清区别：定义、层级、作用、边界 | 元时空与现象时空混用 |
| U4 | 逻辑纪律 | 生成、演化、因果、显化按学说既定链条表述，不跳步、不倒置、不循环 | 「尺度面自动变成空间」 |
| U5 | 限定纪律 | 用现象语汇或类比指称本体、不可描述对象时，标明「仅为指称，非物理实存」 | 「序生场是物理场」 |
| U6 | 断言纪律 | 不引入未定义的物理结论或超验断言；模型表述保持模型身份 | 「时间就是量子涨落」 |
| U7 | 溯源纪律 | 新增判断须能由既有定义推出，或能回查到原文；转述须标明 | 无出处的全新结论 |

## 二、七条一致性标准

| # | 标准 | 检查点 |
|---|---|---|
| C1 | 定义一致 | 问答/关系使用的术语、分类、层级，与现行定义一致 |
| C2 | 关系正确 | 方向、类型、层级正确；目标术语存在；类型与层级匹配 |
| C3 | 引文可回查 | 证据能逐字回查；转述须标明，不冒充原文 |
| C4 | 概念澄清 | 能回答「是什么、不是什么」，必要时给出最小定义 |
| C5 | 边界划定 | 说明适用条件、与相邻概念的分界、常见误用或反例 |
| C6 | 机制解释 | 涉及生成、变化、因果的，须说明「通过什么机制」，不能只给结论 |
| C7 | 体系自洽 | 不与其他条目冲突；不循环论证；推演链条闭合 |

## 三、标准的适用方式

- U1–U7 对全部条目适用；
- C1–C3 对全部条目适用；
- C4–C6 只在条目**作出解释性判断**时适用：单纯的定义问答不必强行加边界或机制；
- 领域差异只作为**检查示例**，不写成硬标准：

| 领域 | 检查示例 |
|---|---|
| 本体论 | 结构面 vs 元实体；元时空 vs 现象时空 |
| 序生体系 | 观测/测创；涌现与生成 |
| 元意识体系 | 本源不可描述；现象语汇的限定 |
| 元子社会 | 制度机制、权责边界、适用条件 |

## 四、判定与力度

| 判定 | 含义 |
|---|---|
| 无需调整 | 已清晰、自洽、可回查 |
| 微调 | 措辞可更准确，但不影响理解 |
| 修正 | 有明确越界、逻辑跳步或术语误用 |
| 待定 | 涉及学理判断，需作者裁定 |

审校力度：

1. 全量规则扫描；
2. 对「有标记」和「高风险条目」人工复核；
3. 已清晰、逻辑严密的条目**不强行改写**；
4. 预期改动只占少数，最终给出变更集供作者复核。

## 五、输出

- 逐条工作簿：每条一行，含判定、问题、建议；
- 汇总报告：改了多少、为什么改、哪些待定；
- 变更集：只列实际修改的条目。

## 六、证据与备注（v3，2026-11-21）

### 证据

- 有完整段落的，用整段，不截句；
- 多几个字节不是问题，解释力更重要；
- 整段能同时提供上下文、边界与因果链，优先于单句；
- 引文保持原文，不改写、不拼接。

### 备注

- 元意识学说思维密度高，不能假设读者熟悉体系；
- 凡关系方向容易读反、术语容易混淆、边界容易越界的地方，尽量加备注；
- 备注只解释「这句话在说什么、不说什么」，不引入新论断；
- 备注是给第一次接触的人看的，不是给作者看的。

### 示例

- #11 个体元意识 —认知行为→ 元识：
  - 证据用 p45 整段；
  - 备注：「元识是个体元意识的认知行为；不是说个体元意识由元识产生。」

## 七、不确定处理（v4，2026-11-21）

元意识学说是开放学说，本源还有多面，很多地方尚未深入思考或无法表述。

因此：

- 拿不准的关系，**删除或简化**，不强行补全；
- 无法逐字回查的，不冒充原文；
- 边界不清的，降为 mention，或只保留定义；
- 未想清楚的面，标注「待定」，不提前概念化；
- 体系会持续迭代，允许后续版本修改。

判断标准不是「关系图是否完整」，而是「这条关系是否有把握、可回查、不误导」。
