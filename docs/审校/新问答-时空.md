# 新问答草案：空间和时间是元实体吗？

> 状态：待作者核定，暂不写入知识库。
> 依据：作者 2026-11-19 确认的「尺度侧 / 节拍侧」表述。

## 问题

**空间和时间是元实体吗？**

## 完整回答

空间与时间不是两种元实体。元实体指元时空中的实在，以元态能量形式存在；空间与时间不是「物」，而是同一本体面——尺度面——在现象时空的两个显化侧：尺度侧显化为广延（空间），节拍侧显化为先后（时间）。序生场不是物理场，而是使物理场得以显现的前物理条件；「势差」「场」只是现象语汇对本体的指称，不是物理实存。现象时空，就是这两侧在观测中被共同测创出的时空整体。

## 关联术语

- 尺度面
- 序生场
- 现象时空
- 元实体与现象实体
- 元时空
- 观测创造实在

## 设计说明

1. **先否定**：「不是两种元实体」，直接回应问题；
2. **再定位**：元实体是元时空中的实在，空间/时间不是物；
3. **给结构**：同一尺度面的两个显化侧，尺度侧与节拍侧；
4. **加限定**：序生场非物理场，势差/场是现象语汇；
5. **补机制**：经观测/测创，避免「自动显化」。
