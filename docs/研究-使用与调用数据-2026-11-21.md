## 四、结论

1. 渠道已经铺开，但真实外部使用接近零；
2. PyPI 下载量高，与真实调用不匹配，不能当用户数；
3. 37 个独立问题里，最高频的“什么是元识”很可能是自测；
4. ModelScope 有 255 次数据集下载、37 次 MCP 页浏览，但 0 次 MCP 调用；
5. Zenodo 有浏览、少量下载，说明学术侧有零散关注，但未形成引用；
6. 当前问题不是“渠道不够”，是“没有真实使用场景与案例”。

## 五、建议

1. 先在本地/API 日志里区分“自测”和“外部调用”（加 client 标识或来源）；
2. 找一个真实使用者做一次完整案例，而不是继续铺渠道；
3. 公众号/文章入口继续按计划加，但不要期待立刻起量；
4. 下次复盘只看三个数：真实外部调用、站点访问、第三方引用。
