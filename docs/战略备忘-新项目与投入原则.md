# 战略备忘：投入原则与新项目（2026-11-04）

## 一、主体资质

- 公司：**元意识（重庆）人工智能科技有限公司**；
- 意义：国内 MCP 平台多为企业开放或需企业认证，我们具备直接申请的条件；
- 待办：整理营业执照、对公账户、法人信息，形成一份「平台入驻资料包」，一次准备、多处复用。

## 二、费用原则

- **优先一次性付款**：认证费、上架费、一次性审核费可以投入；
- **按月/按年订阅暂缓**：在三个核心数出现增长前，不背固定成本；
- 单笔支出设上限，超过上限先讨论再付；
- 所有付费渠道记入台账，注明金额、周期、到期日。

## 三、判断标准（不变）

平台数量不是进度。只看三个数：

1. 每周真实调用数（MCP / HTTP）；
2. 内容带来的站点访问；
3. 第三方引用或使用案例。

三个数不动，扩渠道不是重点。

## 四、mcai-knowledge 的定位

- 长周期项目，服务 Meta-Consciousness Theory，方向细分、冷门，这是事实，不是问题；
- 不追热点、不改节奏、不急功近利；
- 目标不是短期盈利，是「可被调用、可被引用、可被继承」。

## 五、新项目（第二阶段）

### 立项前提

mcai-knowledge 达到「基本完成」后再启动，标准建议：

- 核心文档、API、MCP 稳定，三个月内无破坏性变更；
- 每周有稳定调用（哪怕数量不大）；
- 至少一个第三方引用或案例；
- 现有维护进入每周固定少量时间的状态。

### 项目原则

- 与 mcai-knowledge **无直接关系**，独立品牌、独立仓库；
- 以**收费盈利**为目标，允许商业化；
- 借鉴市场上已验证的付费 MCP 产品，不凭空想象需求；
- 优先选择：需求明确、交付标准化、支持成本低、可一次性收费或按用量收费的方向。

### 选题标准（待调研后填充）

- 是否有现成的付费同类产品，价格与量级如何；
- 目标用户是否已在为类似能力付费；
- 是否能在一个月内做出可用版本；
- 是否依赖我们不拥有的数据或资质。

### 反哺关系

新项目盈利后，反哺 mcai-knowledge 的长期维护与基础设施成本；两者账目分开，不混用。

## 六、风险

- **注意力分散**：新项目启动后，mcai-knowledge 的固定维护时间必须写进日程，不能被挤掉；
- **过早商业化**：mcai-knowledge 不接广告、不做付费墙，保持可引用；
- **选题跟风**：只做已验证的付费需求，不做「看起来会火」的方向。

## 七、时间点

- 现在到 2026 年底：mcai-knowledge 补充与运营，不启动新项目；
- 2027 年 Q1：复盘三个数，若达到立项前提，启动新项目调研；
- 调研期 2–4 周，产出选题清单与成本估算，再决定是否投入。
