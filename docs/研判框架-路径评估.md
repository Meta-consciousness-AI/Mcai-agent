# 研判框架：路径评估

> 用途：给每条候选路径打分，决定「先调研、可做、暂缓、不做」。
> 原则：竞争不是否决项；每条路径必须有结论。

## 一、七个维度

| 维度 | 问什么 | 权重 |
|---|---|---|
| 需求证据 | 有没有人已经在为这件事花钱或花时间 | 高 |
| 独有性 | 我们有没有别人拿不到的东西 | 高 |
| 竞争格局 | 谁在做、强在哪、弱在哪 | 中（不否决） |
| 后发可能 | 晚做是否仍能赢，靠什么赢 | 中 |
| 资源匹配 | 现有能力与人手能否支撑 | 中 |
| 时间窗口 | 现在做与两年后做的差别 | 中 |
| 失败成本 | 做错了损失多大、能否撤回 | 高 |

## 二、判定档位

| 档 | 含义 | 动作 |
|---|---|---|
| A | 证据强、独有性高、失败成本可控 | 立即进入调研 |
| B | 有机会，但有关键未知 | 调研后再定 |
| C | 条件未成熟 | 记录触发条件，暂缓 |
| D | 明确不做 | 写下理由 |

## 三、后发优势的判断标准

晚进入仍可能赢，通常满足其一：

1. **分发优势**：有现成渠道触达用户；
2. **成本优势**：同样的事，我们做得更便宜；
3. **整合优势**：把分散能力合成完整体验；
4. **地域/合规优势**：本地市场、语言、资质；
5. **耐力优势**：别人撤了我们还在。

不满足任何一条，后发就是劣势。

## 四、每个结论必须写三行

1. 选它的理由；
2. 不选其他路径的理由；
3. 如果它错了，多久能知道、损失多少。

## 五、复盘

每条进入 A 档的路径，设一个复盘点：

- 时间：调研开始后 2–4 周；
- 条件：出现或不出现什么信号；
- 动作：继续、转向、停止。
