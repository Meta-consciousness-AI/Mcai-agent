# 工作法：理论雷达

> 时间：2026-11-18
> 目的：持续发现与元意识学说可能相关的新理论，及时判断「可引用、可观察、需警惕」。
> 定位：这是长期机制，不是一次性任务。

## 一、为什么要有

1. 同类理论出现，会改变外部环境与公众认知；
2. 有些理论可以支撑我们，有些会拖累我们；
3. 不主动跟踪，就会在别人问起时一无所知；
4. 跟踪不等于附和，也不等于合并。

## 二、频率

- **常规扫描**：每月一次，30 分钟；
- **触发扫描**：出现以下任一情况，当天记录：
  - 有人提到某个新理论；
  - 某理论被媒体报道或引发争议；
  - 某理论被撤稿、被 replication 失败；
  - 出现与「元意识」同名的概念。

## 三、关键词

中文：

```
意识第一性、意识场、基础意识场、通用意识场、非二元、
观测者、意识本体论、泛心论、唯心论、序生
```

英文：

```
fundamental consciousness, universal consciousness field,
consciousness as fundamental, non-dual, panpsychism,
idealism, observer-created reality, first-person ontology
```

## 四、来源

| 类型 | 去处 |
|---|---|
| 预印本 | arXiv、PhilPapers、Zenodo、SSRN |
| 期刊 | AIP、Springer、Elsevier、MDPI |
| 中文 | 知网、万方、公众号、豆瓣 |
| 讨论 | Google Scholar 引用、Reddit、X |
| 撤稿 | Retraction Watch |

## 五、记录字段

每条一行，字段固定：

| 字段 | 说明 |
|---|---|
| 名称 | 理论名（中英） |
| 作者/机构 | 谁提出、在哪 |
| 发表处与时间 | 期刊/预印本/书 |
| 核心主张 | 一句话 |
| 与元意识重合点 | 具体到概念 |
| 关键差异 | 结构、方法、落点 |
| 证据状态 | 同行评议 / 预印本 / 撤稿 / 争议 |
| 风险 | 伪科学标签、超常主张、政治敏感 |
| 处置 | A 可引用 / B 观察 / C 警惕 |

## 六、处置规则

- **A 可引用**：有同行评议、主张克制、与我们有明确重合点；引用时注明出处与状态；
- **B 观察**：方向相关但证据不足；只记录，不对外引用；
- **C 警惕**：已撤稿、含超常主张、或明显不严谨；记录并标注，不靠近。

三条硬规则：

1. 不合并理论，不宣称「同一理论」；
2. 不借势，不用别人的关注度替代自己的证据；
3. 不碰超常主张（ telepathy、濒死、死后意识等）。

## 七、输出

- 每月一份：`docs/理论雷达/YYYY-MM.md`；
- 重要条目单独写研究笔记，放 `docs/`；
- 结论同步到 `docs/工作原则.md` 的「外部理论」一节（如需要）。

## 八、与已有机制的关系

- 与本项目「先调查、再动手」一致：理论雷达是调查的一部分；
- 与「反馈驱动」一致：外部理论也是信号；
- 与「不可穿透性」一致：所有理论都只是模型，包括我们自己的。
