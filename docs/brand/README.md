# MCAI·元 图形标：草图

## 思路

「元」的甲骨文、金文写法，是一个侧立的人形，头部用一个圆点突出；本义是「人头」，引申为「开始」。
（来源：香港中文大学《汉語多功能字庫》「元」字条）

所以图形只保留两个元素：

- 一个圆点：头，也是「始」；
- 一条人形弧线：身体。

草图，仅用于方向确认；还不是最终标志。

需要继续调整的点：

3. 与文字 `MCAI·元` 的组合方式（点在中间、点在头顶）还未定。

## 2026-11-18 第二轮：按「元」的比例重画

参考了《元》字形演变（商甲骨—金文—西周—春秋战国—小篆—隶—楷）：

- 商甲骨、金文：人形 + 头点，本义「头」；
- 西周：加上横；
- 小篆：定型为「一 + 兀」，即两横 + 两腿；
- 楷书：今天的「元」。

新方案：

| 文件 | 说明 |
|---|---|
| `mcai-yuan-mark-e2.png` | 两横 + 两腿，腿略外撇 |
| `mcai-yuan-mark-e3.png` | 两横 + 两腿，腿更直、上横更短，最像「元」 |
| `mcai-yuan-mark-e2-64.png` / `e3-64.png` | 64px 缩小检查 |

结论：E3 在 64px 下仍能读作「元」，可作为主标方向；C/D/F 的人形方案更像通用「人」图标，降为辅助图形候选。
