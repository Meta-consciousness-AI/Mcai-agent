# MCAI·元 图形标：草图

## 思路

「元」的甲骨文、金文写法，是一个侧立的人形，头部用一个圆点突出；本义是「人头」，引申为「开始」。
（来源：香港中文大学《汉語多功能字庫》「元」字条）

所以图形只保留两个元素：

- 一个圆点：头，也是「始」；
- 一条人形弧线：身体。

## 当前状态

草图，仅用于方向确认；还不是最终标志。

需要继续调整的点：

1. 现在两条腿偏直，可以再做一点外弧，减少「火柴人」感；
2. 头点与人形之间的间距可以再试两档；
3. 与文字 `MCAI·元` 的组合方式（点在中间、点在头顶）还未定。
