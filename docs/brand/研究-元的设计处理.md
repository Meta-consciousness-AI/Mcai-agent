# 研究：「元」在设计中的处理方式

> 时间：2026-11-18
> 范围：国内设计平台、高校设计研究、商业品牌、专业机构，以及可购买的字形素材。
> 目的：为 `MCAI·元` 的图形部分提供参考，不急于定稿。

## 一、六类处理方式

### 1. 古文字直用（篆体/甲骨）

**比亚迪「元」**（2016）：车头、方向盘、轮毂、尾部都用篆体「元」，是首款用汉字做车标的车型；前脸格栅与保险杠还共同构成「元」的字形。

- 启示：篆体「元」在徽章尺寸下可读，且文化感强；
- 风险：篆体细节多，缩小到 favicon 会糊。

来源：[汽车产经网](https://www.autoreport.cn/hangye/20050829/0300018059.html)、[人民网](http://auto.people.com.cn/n1/2016/0304/c1005-28170178.html)

### 2. 单字放大（书法/字体）

**元气森林**：把「气」（早期「気」）放大成包装主视觉，成为品牌资产；后来把「気」改成「气」，理由是便于检索。

- 启示：单字可以撑起一个品牌；
- 风险：单字越强，越依赖字形的独特性；换字会伤品牌资产。

来源：[FBIF](https://m.hexun.com/stock/2023-02-15/207802546.html)、[界面新闻](https://baijiahao.baidu.com/s?id=1680605648301835322)

### 3. 几何化重构（高校/专业）

**清华美院陈楠**：甲骨文设计字库、「格律设计」理论，用几何化、装饰性的当代语言重构古文字，而不是照搬斑驳刀刻。

- 启示：先提取结构，再几何化；
- 风险：过度几何化会失去字源，变成普通图形。

来源：[清华美院](https://www.ad.tsinghua.edu.cn/info/1227/15454.htm)、[清华大学](https://www.tsinghua.edu.cn/info/1182/125505.htm)

### 4. 圆 / 零的意象

**元人动画（SOULAR）**：把 O 解释为「零，寓意混沌初开，万物之始」，也代表「圆，包罗万象」。

**元一文化**：圆形融合「元一」二字，取「大道至简」。

- 启示：「元」与「圆/零」的语义天然相通，可用圆点、圆环；
- 风险：圆太常见，容易失去辨识度。

来源：[黄扬设计](https://huangyangdesign.com/SOULAR)、[红动中国](https://m.redocn.com/design/case/2117.htm)

### 5. 结构/环境构成

**比亚迪元**：前脸格栅与前保险杠共同构成「元」字。

**方元文创**：用飞檐、窗花构成标志，取「元」的谐音「圆」。

- 启示：图形不必是一个字，可以是一组结构；
- 适用：线下空间、展陈、门头。

来源：[汽车产经网](https://www.autoreport.cn/hangye/20050829/0300018059.html)、[站酷](https://www.zcool.com.cn/work/ZNDY0MjA2MDA%3d.html)

### 6. 现成字形素材

字体家等平台有可商用的「元·甲骨文」PNG 素材，也有整套甲骨文设计字库。

- 启示：若不想自绘，可购买授权；
- 风险：素材可能被多人使用，独特性不足。

来源：[字体家](https://www.zitijia.com/cs/item/31769)

## 二、对 MCAI·元 的意义

| 观察 | 对我们的用法 |
|---|---|
| 篆体元可做徽章 | 适合印章、头像，但要做简化 |
| 单字可撑品牌 | 我们已有 `MCAI·元` 文字标，不需要再造单字 |
| 几何化要保留字源 | E3 方向正确，但需再调比例 |
| 圆/零意象成立 | 可把「头点」做成圆，与「元=始」呼应 |
| 结构构成适合线下 | 以后做展陈、门头时可用 |
| 素材可商用 | 备选，不自绘时的退路 |

## 三、三个可选图形方向

### 方向 1：篆体「元」简化版

- 取小篆「元」的结构，减笔画、加粗、圆角；
- 像印章，适合头像、水印；
- 参考：比亚迪元、篆刻。

### 方向 2：几何「元」（E3 延续）

- 两横 + 两腿，现代几何；
- 适合 UI、favicon、文档页眉；
- 参考：陈楠格律设计。

### 方向 3：圆点 + 圆环（符号化）

- 一个点（头）+ 一个圆环（始/圆）；
- 最抽象，辨识度靠长期使用建立；
- 参考：元人动画的 O、元一文化的圆。

## 四、我的建议

- 主标已定 `MCAI·元`，不再动；
- 图形先做**方向 1 与方向 2 各一版**，放在一起比；
- 方向 3 风险最高，暂不投入。
