# 工作法：线上获客与试点

> 目标：用网络检索找到目标客户，用邮件建立联系，拿到第一个真实试点。
> 原则：少而准，不群发，不发垃圾邮件。

## 一、目标客户画像（ICP）

优先顺序：

1. **学术/古籍类出版社**：出版古籍整理、社科著作、学术专著；
2. **高校学报与社科期刊**：每期有大量引文与参考文献；
3. **数字人文实验室**：有文本核对需求，懂技术；
4. **Agent/RAG 团队**：需要引用核验能力。

排除：

- 大众出版（引文少）；
- 教辅（格式固定）；
- 无编辑部的机构。

## 二、找客户的渠道

| 渠道 | 怎么用 |
|---|---|
| 出版社官网 | 「联系我们」「版权页」「编辑邮箱」 |
| 期刊官网 | 编委会、编辑部邮箱、投稿系统 |
| 知网期刊页 | 期刊主办单位、编辑部信息 |
| 高校出版社 | 学校官网下的出版社页面 |
| 数字人文中心 | 高校/研究院网站 |
| 公众号 | 出版社/期刊官方号，留言或菜单里的联系方式 |
| 招聘信息 | 编辑岗位 JD 常写业务范围与邮箱 |

## 三、筛选标准（满足三条再联系）

1. 近两年出版过古籍整理或学术著作；
2. 有公开的编辑部联系方式；
3. 内容以引文密集为特征（史学、哲学、文学、法学）。

## 四、名单字段

| 字段 | 说明 |
|---|---|
| 机构 | 出版社/期刊名 |
| 类型 | 出版社 / 期刊 / 实验室 / 公司 |
| 地点 | 省市 |
| 相关出版物 | 近两年 1–2 本/期 |
| 联系方式 | 邮箱优先 |
| 来源链接 | 从哪找到的 |
| 状态 | 未联系 / 已发 / 已回 / 拒绝 / 试点 |

## 五、邮件模板（中文，短）

主题：

```
关于书稿引文核对的一个免费试点
```

正文：

```
您好，

我是元意识知识资产项目的负责人。我们做了一套引文核验工具：给定书稿和原文，逐条比对引文是否与原文一致，指出差异位置，不改写原文。

看到贵社/贵刊出版过《XXX》，引文密度较高，想请教：是否愿意拿一部书稿或一期稿件做一次免费试点？我们出一份差异报告，供编辑部评估。

我们不收取费用，也不要求独家；报告只给贵方，不外传。

如果方便，回复本邮件即可；也可电话沟通。

此致
Meta-consciousness-AI
3818490932@qq.com
```

## 六、发送与跟进

- 一次只发 5–10 封，逐封改写第一段（提到具体书/刊）；
- 5 个工作日没有回复，跟进一次，不超过两次；
- 明确拒绝的，记录原因，不再联系；
- 回复的，24 小时内给方案。

## 七、合规与边界

- 不使用爬虫批量抓邮箱群发；
- 每封邮件有真实署名与联系方式；
- 提供「不再联系」选项；
- 不伪造机构身份，不夸大能力；
- 遵守邮箱服务商与平台规则。

## 八、指标

| 指标 | 目标（首月） |
|---|---|
| 有效名单 | 30 家 |
| 发出邮件 | 30 封 |
| 回复率 | ≥15% |
| 试点意向 | ≥2 家 |
| 实际试点 | 1 家 |

## 九、里程碑与止损

- 第 2 周：名单 30 家，发出首批 10 封；
- 第 4 周：回复 ≥5 家，试点意向 ≥2 家；
- 第 8 周：跑完 1 个试点；
- 第 8 周仍无回复：换细分（期刊 vs 出版社）或换话术，不硬撑。

## 十、为什么这件事现在能做

- 检索与筛选可以半自动化；
- 邮件是出版社的日常沟通方式；
- 我们的工具是现成的，试点成本低；
- 不需要先建平台，先服务一个人。
