# 命名规范

全项目统一使用 **mcai**（Meta-consciousness-AI 的缩写）。

| 对象 | 命名 |
|---|---|
| PyPI 包 | `mcai-knowledge` |
| 命令行 | `mcai` / `mcai-mcp` |
| Python 模块 | `mcai` |
| 环境变量 | `MCAI_HOME` / `MCAI_TOKEN` |
| MCP 服务器名 | `mcai-knowledge` |
| 资源 URI | `mcai://` |
| GitHub 仓库 | `mcai-agent` |
| 品牌文案 | MCAI |

不要再用 `mca` 作为对外名称。旧包 `mca-knowledge` 已废弃。
