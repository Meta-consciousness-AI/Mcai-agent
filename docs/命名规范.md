# 命名规范（中英文统一版）

> 2026-11-18 修订：中文称呼统一 MCAI；英文标识分三层管理。

## 一、三层命名

| 层 | 用途 | 规则 |
|---|---|---|
| 品牌层 | 对人、对外的称呼 | 用 **MCAI**，全大写 |
| 学说层 | 理论名称 | 用 **Meta-Consciousness Theory**，首字母大写、连字符 |
| 技术层 | 包名、命令、接口、URL | 全小写，用连字符或下划线 |

## 二、规范写法

| 对象 | 规范写法 | 说明 |
|---|---|---|
| 品牌 / 团队 | **MCAI** | 全大写，任何场合 |
| 机构 / 账号 | **Meta-consciousness-AI** | 连字符，AI 大写；GitHub、Gitee、平台账号 |
| 学说英文名 | **Meta-Consciousness Theory** | 每个词首字母大写，中间连字符 |
| 产品 / PyPI 包 | `mcai-knowledge` | 全小写，代码格式 |
| MCP 服务名 | `mcai-knowledge` | 全小写 |
| 命令 / 模块 | `mcai`、`mcai-mcp` | 全小写 |
| MCP 工具名 | `mcai_answer`、`mcai_concept`、`mcai_search`、`mcai_related`、`mcai_cite`、`mcai_provenance`、`mcai_list` | 小写 + 下划线 |
| 命名空间 | `https://w3id.org/mcai/` | 全小写 |
| 数据集标题 | MCAI Knowledge Base | 标题用 MCAI |
| 文档标题 | MCAI … | 例：MCAI Knowledge Base Dataset |

## 三、禁用写法

| 不要写 | 应写 |
|---|---|
| mca、Mca | MCAI |
| Mcai、Mcai- | MCAI（品牌）；`mcai-`（技术标识） |
| MCAI-Knowledge、MCAI_Knowledge | `mcai-knowledge` |
| MetaConsciousness | Meta-Consciousness Theory（学说）或 MCAI（品牌） |
| Meta Consciousness（无连字符） | Meta-Consciousness Theory |
| Meta-consciousness theory（小写 theory） | Meta-Consciousness Theory |
| mcai-Knowledge | `mcai-knowledge` |

## 四、历史标识（已发布，不改）

| 标识 | 原因 |
|---|---|
| PyPI `mcai-knowledge` | 下载与安装命令依赖 |
| 命令 `mcai` / `mcai-mcp` | 用户配置已写 |
| 模块 `mcai` | 代码 `import mcai` |
| 环境变量 `MCAI_HOME` / `MCAI_TOKEN` | 部署配置依赖 |
| 仓库 `Mcai-agent` / 目录 `mca-agent` | 克隆地址与历史链接 |
| w3id `https://w3id.org/mcai/` | PR 已合并 |
| DOI `10.5281/zenodo.*` | 永久标识 |
| HTTP 头 `X-MCAI-Client` | 接口字段 |

历史标识只在技术上下文中出现；**新项目、新包、新仓库、新域名一律按上表命名**。

## 五、场景示例

**README 首段**：

> MCAI builds verifiable knowledge assets. The Meta-Consciousness Theory knowledge base is distributed as `mcai-knowledge` and served through an MCP endpoint.

**邮件署名**：

> MCAI（Meta-consciousness-AI）

**投稿作者**：

> 元意识（重庆）人工智能科技有限公司（MCAI，元意识AI团队）

**平台简介**：

> MCAI：可核验知识库，每条定义与引文都带原文出处。

## 六、自检

改完文案后，用这几个词搜一遍：

```
mca、Mca、Mcai、MCAI-、Meta Consciousness、MetaConsciousness、mcai-Knowledge
```

除历史标识外，出现即改。
