# 应用内清理指南（只清缓存，不动数据）

> 时间：2026-11-18
> 目标：释放空间，不影响登录状态、聊天记录与后续操作。
> 原则：只清缓存、临时文件、旧安装包；聊天记录与文档先确认再动。

## 一、微信（占用最大）

**路径**：微信左下角「更多 / 三横」→ 设置 → 存储空间 → 管理

- 可清：缓存、聊天中的图片/视频/文件（按大小排序）；
- 保留：文字聊天记录（清理时可勾选「保留文字」）；
- 注意：删除的聊天文件不可恢复，先确认没有要留的合同、资料。

**文件位置**（清完可在资源管理器确认）：

```
C:\Users\HP\Documents\xwechat_files
C:\Users\HP\Documents\WeChat Files
```

## 二、QQ

**路径**：QQ 左下角「三横」→ 设置 → 基本设置 → 文件管理

- 点「清理缓存」；
- 点「打开个人文件夹」，删除 `FileRecv` 里不需要的接收文件；
- 不动 `Msg3.0.db` 等聊天数据库。

## 三、夸克浏览器

**路径**：夸克右上角「三横」→ 设置 → 隐私与安全 → 清除浏览数据

- 勾选：缓存的图片和文件、Cookie 以外的临时数据；
- 不勾：密码、自动填充、书签；
- 另外检查「下载」列表，删掉不再需要的大文件。

**注意**：`AppData\Local\Programs\Quark` 里 5.7GB 是程序本体，**不要手删**；要减只能卸载重装或清理浏览器数据。

## 四、WPS

**路径**：WPS 首页 → 右上角「设置」→ 配置和修复工具 → 高级 → 清理缓存

或：WPS → 文件 → 备份中心 → 本地备份

- 可清：旧版本备份、临时文件；
- 保留：最近 1–2 个备份；
- 备份目录：

```
C:\Users\HP\AppData\Roaming\Kingsoft\office6\backup
```

## 五、抖音（PC 版）

**路径**：抖音右上角「三横」→ 设置 → 存储 → 清理缓存

- 只清缓存，不动作品与登录。

## 六、爱奇艺

**路径**：爱奇艺 → 设置 → 下载设置 / 缓存管理

- 清「已看完」的缓存视频；
- 不动账号信息。

## 七、Edge

**路径**：Edge 右上角「…」→ 设置 → 隐私、搜索和服务 → 清除浏览数据 → 选择要清除的内容

- 勾选：缓存的图像和文件、临时数据；
- 不勾：密码、自动填充、历史记录（看你需要）；
- 时间范围选「所有时间」。

## 八、Windows 自带（可选）

**设置 → 系统 → 存储 → 临时文件**：勾选「临时文件」「缩略图」「传递优化文件」。

或运行 `cleanmgr`，只勾「临时文件」「缩略图」「下载（可选）」。

## 九、不要动

- 各应用的登录态与聊天数据库；
- `AppData\Local\Programs` 下的程序目录；
- 系统目录、驱动、字体。

## 预期收益

| 应用 | 可释放 |
|---|---:|
| 微信/QQ | 3–6 GB |
| 夸克 | 1–3 GB（浏览器数据） |
| WPS | 0.5–1.5 GB |
| 抖音/爱奇艺 | 0.5–2 GB |
| Edge | 0.5–1 GB |
