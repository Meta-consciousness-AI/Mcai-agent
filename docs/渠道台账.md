## 五、季度扫描清单

每季度执行一次，约半天：

1. 搜索新出现的 MCP 市场 / 目录（关键词：MCP marketplace、MCP 广场、MCP 导航）；
2. 检查已上渠道是否仍在线、版本是否最新；
3. 检查是否有平台新开放第三方入驻；
4. 更新本台账的状态与复查日期；
5. 把值得尝试的渠道列入下季度计划，不立即投入。
