## 三、为什么这么写（四句关键措辞）

1. **把那句声明拆开说**：前半与事实有出入、后半属实。精确交代比笼统道歉可信，也让编辑部看到我们分得清哪句错、哪句对。
2. **只说「研究内容同源」，不说「完全不同」**。是否构成重复发表由编辑部判定，不由我们自己先下结论——替对方下结论，反而像在引他往轻里判。
3. **主动给出撤回选项**：把决定权交回去，同时表明不使对方为难。最坏结果是正常退稿，而不是被记一笔。
4. **不写「恳请录用」「请宽限」**。这一封是来问规则的，不是来求情的；求情会让编辑部更难办。
