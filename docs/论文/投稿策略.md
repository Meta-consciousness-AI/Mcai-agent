# 论文投稿策略

> 时间：2026-11-17
> 原则：全力以赴做事，不对结果抱太多期望；尽心尽力即可。

## 一、三层路径

### 第一层：目标期刊

- 《数字人文研究》（人大，季刊，不收版面费，审稿约 1–3 个月）；
- 若初审退稿或选题不符，进入第二层。

### 第二层：其他期刊与会议

按匹配度依次尝试：

| 去处 | 类型 | 说明 |
|---|---|---|
| 《数字人文》（集刊） | 中文集刊 | 审稿较慢，但方向对口 |
| 《图书情报工作》 | 中文期刊 | 需理论或实证贡献 |
| 《情报理论与实践》 | 中文期刊 | 可用「实践」角度切入 |
| 《图书馆论坛》 | 中文期刊 | 偏实践 |
| JCDL / TPDL | 国际会议 | 需英文全文，截稿多在年初 |
| LREC 2028 | 国际会议 | 资源论文，两年一届 |
| DH2028 | 国际会议 | 周期长 |

规则：同一时间只投一家；被拒后再投下一家，不改多投。

### 第三层：行业论坛与公开平台

如果期刊与会议都不成：

1. **掘金**：技术长文，保留方法、数据与复现细节；
2. **知乎**：问题向长文，面向研究者与编辑；
3. **公众号**：精简版，给现有读者；
4. **预印本**：Zenodo / PhilArchive 已有，正式版可再挂一次并更新 DOI 说明。

规则：行业平台不等于降级，而是换读者；方法与数据不简化。

## 二、判定与节奏

| 节点 | 时间 | 动作 |
|---|---|---|
| 投出第一层 | 定稿后 1–2 周内 | 在线投稿 |
| 无回复 | 满 2 个月 | 礼貌询问一次 |
| 退稿 | 收到即改投 | 按审稿意见修订后投第二层 |
| 第二层全部退稿 | — | 转第三层，不拖延 |

## 三、每次投稿前必做

1. 查该刊最新投稿指南与格式模板；
2. 核对数字口径（64/122/270/213、10/13/12、100%、78 题）；
3. 确认署名（公司全称 + MCAI）与通讯邮箱；
4. 附注中的作品登记信息保留；
5. 英文摘要与关键词准备。

## 四、心态

- 目标是「让方法被看到」，不是「必须发表在某一刊」；
- 期刊是渠道之一，不是成败标准；
- 被拒是常态，改投即可；
- 不因等待而停下手上的其他工作。
