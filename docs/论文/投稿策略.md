# 论文投稿策略（v2）

> 时间：2026-11-17
> 原则：全力以赴，不对结果抱太多期望；尽心尽力即可。
> 重要：多数期刊要求「未曾在其他出版物或互联网公开发表」，因此**学术投稿必须在行业平台发布之前**。

## 一、首发约束（决定顺序）

《数字人文》（清华、中华书局）的版权协议明确要求：作品「未曾在其他出版物或互联网上公开发表过」。

这意味着：

- 投稿前不能先在掘金、知乎、公众号发布；
- 预印本也要谨慎：部分期刊视预印本为「已公开」，投前先问编辑部；
- 一旦在行业平台发布，学术期刊这条路基本关闭。

**正确顺序：学术期刊 → 学术会议 → 行业平台。**

## 四、行业平台（最后）

前提：学术期刊与会议都已尝试，或被明确拒绝。

1. 掘金：技术长文，保留方法与数据；
2. 知乎：问题向长文；
3. 公众号：精简版；
4. 个人站点与预印本：更新说明。

规则：方法与数据不简化；注明「本文曾投稿学术期刊」不必，但不得虚构已发表。

## 五、已定事项（2026-11-17）

- **首发确定**：《数字人文》（清华 + 中华书局）；
- 其余期刊与会议的先后顺序，待首发投出后再过一遍；

## 六、节奏

| 节点 | 动作 |
|---|---|
| 定稿后 1 周 | 投《数字人文》（清华） |
| 满 2 个月无回复 | 询问一次 |
| 退稿 | 按意见修订，投《数字人文研究》或《图书情报工作》 |
| 国内连续退稿 | 视情况转英文，投 DHQ / First Monday / JDHASA |
| 全部不成 | 转行业平台，不拖延 |

## 六、判断标准

- 国内优先，但不把「国内」当唯一；
- 一般院校学报也是选项，只要方向对口；
- 不因等待而停下手上的其他工作；
- 被拒是常态，改投即可。
