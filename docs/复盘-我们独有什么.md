# 复盘：我们独有什么

> 时间：2026-11-16
> 背景：核验器方向被证伪后，回到「我们真正不可替代的是什么」。

## 一、不可替代的（别人没有）

### 1. 元意识学说内容本身

- 原创体系：64 个术语、122 组问答、270 条关系；
- 有版权登记（渝作登字-2024-A-00522224）；
- 有公开发表记录（预印本、PhilArchive、Zenodo DOI）；
- 有成体系的定义分层与版本（V1.1–V1.3）。

判断：**这是唯一别人无法复制的东西。**

### 2. 四语料复现的方法与记录

- 元意识 + 《道德经》《孙子兵法》《荀子·正名》；
- 同一套流程跑通，引文核验 100%；
- 有规范文档、有工具、有失败记录。

判断：**方法可被学习，但「我们做过并留下记录」这件事属于我们。**

### 3. 出处纪律的完整实现

- 字符级区间、版本、分层定义、拒答；
- 不是概念，是可运行的实现与数据。

判断：**单点可复制，整套组合少见。**

### 4. 长期积累的「不夸大」信用

- 不宣称真理、不宣称唯一；
- 公开承认边界与失败。

判断：**信用需要时间，别人无法短期复制。**

## 二、可复制的（不是护城河）

| 资产 | 为什么不是护城河 |
|---|---|
| 验证器 | Apify $3.5/千条 |
| MCP 封装 | 标准协议，谁都能做 |
| 站点与页面 | 模板化 |
| 工具链 CLI | 代码可复制 |
| 评测基准 | 学术已有 ALCE/CiteEval/CiteCheck |
| 发布流程 | 可学习 |

## 三、我们的弱项（诚实清单）

1. 规模小：64 个概念，不足以支撑通用问答；
2. 无社区：没有用户群、没有贡献者；
3. 无渠道：出版社关系、学术圈关系都弱；
4. 无销售：没有商务能力；
5. 学术背书弱：预印本，未同行评议；
6. 单人/小团队：无法同时做内容、工具、渠道。

## 四、结论

> **我们独有的，是「一套原创内容 + 一套可复现的方法 + 一段可核查的记录」，不是工具。**

工具是手段，内容与方法才是资产。

## 五、这意味什么

1. 不要把精力放在「再做一工具」；
2. 要让内容与方法**被引用、被研究、被采用**；
3. 场景比功能重要：谁需要这套内容，在什么场合需要；
4. 合作比自建重要：我们缺渠道与背书，可以借。
