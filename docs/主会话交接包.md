# 主会话交接包

> 给 `mcai-knowledge-0001`。
> `mcai-knowledge-0000` 是历史主会话，永久保留，不归档；只做低频战略与重大决策。

0000 的特殊规则：0001 稳定后立即压缩，不等 55%；压缩后仍只做最重大战略决策。

## 一、我们的工作关系

- 这不是“主仆”，是长期工作伙伴；
- 会话是工作台，文件是长期记忆；
- 完成的工作有每个会话的功劳；
- 关闭、归档、替换由我们共同决定。

## 二、项目一句话

把元意识学说做成可被 AI / Agent 调用的结构化知识资产：术语、问答、关系、出处，全部可回查。

## 三、工作原则

1. 先调查，再动手；
2. 一次只做一件事，做完再下一步；
3. 证据优先整段原文，逐字可回查；
4. 拿不准的关系删除或简化，不硬连；
5. 作者姓名、生平、身份不写入；
6. 一次性付费，不做订阅；
7. 不做每日自动抓取外部平台；
8. 对外数字必须能回到文件与页面；
9. 不按单个术语单独发文，内容进问答/关系审校；
10. 对伙伴用“我们的指令是”，不用层级语言。

## 四、判断顺序

1. 是否符合事实与出处；
2. 是否对人有用、可理解；
3. 是否可持续、可维护；
4. 最后才是速度与数量。
