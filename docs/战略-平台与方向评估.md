# 平台与方向评估（2026-11）

## 一、MCP 不是最新的平台类型

AI 平台已经分成几层，MCP 只是其中一层：

| 层 | 代表 | 作用 | 成熟度 |
|---|---|---|---|
| 模型层 | GPT、Claude、Qwen、豆包、DeepSeek | 提供推理 | 成熟，巨头垄断 |
| 工具接入层 | **MCP**（Anthropic，2024-11） | 模型调用外部工具/数据 | 事实标准，竞争充分 |
| Agent 协议层 | A2A（Google，2025-04）、AGNTCY | Agent 之间协作 | 早期，标准未定 |
| 支付层 | AP2、x402、Stripe ACP | Agent 之间的付费 | 很早期 |
| 分发层 | ChatGPT Apps、Claude Connectors/Skills、Gemini Extensions、各云 MCP 广场 | 让用户找到工具 | 快速变化 |
| 发现层 | llms.txt、agent.json、MCP registry | 让机器找到内容 | 早期 |

结论：MCP 是「工具接入」这一层的事实标准，但**上面还有 Agent 协议、支付、分发三层在快速变化**。它不是终点，只是当前最可用的一层。

## 二、「国内版」策略的历史条件

20 多年前新浪、网易、百度、淘宝能成，靠的不只是「复制」，而是四个条件：

1. **语言与内容本地化**：中文内容、中文搜索、中文电商；
2. **本地运营与支付**：短信、货到付款、支付宝；
3. **监管与牌照**：外资进不来，本土公司拿牌照；
4. **巨头还没做完**：市场空白，先做的人定义标准。

今天的 MCP / Agent 平台，条件变了：

- **协议是开源的**，不需要「国内版协议」，克隆没有意义；
- **平台层已被巨头占据**：阿里百炼、百度千帆、火山方舟、讯飞、魔搭都在做 MCP 广场，创业公司很难成为「中国的 MCP 市场」；
- **真正的空白在垂直工具与本地生态集成**：微信、飞书、钉钉、抖音电商、小红书这些「中国特有的工作流」，国外工具进不来，巨头也未必做深。

所以「国内版」仍然成立，但对象不是协议或市场，而是**垂直能力与本地系统连接**。

## 三、评估框架

进入任何平台或方向，按七项打分（1–5 分）：

| 维度 | 问题 |
|---|---|
| 准入 | 能否注册、是否要企业认证、审核周期、费用 |
| 流量 | 平台是否有真实 Agent 用户与调用量 |
| 差异 | 我们能否做出别人不容易复制的东西 |
| 付费 | 谁付钱、一次性还是订阅、价格上限 |
| 合规 | 是否需要牌照、数据授权、内容审核 |
| 维护 | 支持成本、API 稳定性、版本变更频率 |
| 协同 | 是否反哺 MCAI，或独立现金流 |

## 四、我们的能力盘点

| 能力 | 现状 | 评价 |
|---|---|---|
| 知识资产化 | 四语料、出处到字符 | 强，可复用 |
| MCP 工程 | 5 工具、双实例、注册表 | 中上，能快速复制 |
| 内容分发 | 十平台，有基础观众 | 中，能冷启动 |
| 企业资质 | 有公司，资料齐全 | 强，可进企业平台 |
| 资金 | 可少量一次性投入 | 中，不能烧钱 |
| 本地生态集成 | 尚未做 | 弱，是最大缺口 |
| 数据授权 | 仅有公共领域文本 | 弱，限制垂直方向 |

## 五、推荐方向（按适配度排序）

### 方向 A：本地 SaaS 连接器（推荐）

- 做什么：把微信/飞书/钉钉/抖音电商的常用操作封装成 MCP 工具；
- 为什么：国外工具进不来，巨头自己做但不深，企业真实需要；
- 付费：按企业一次性部署或按坐席；
- 风险：需要逐个平台申请开放能力，周期长。

### 方向 B：垂直知识库代做（推荐，与 MCAI 协同）

- 做什么：帮企业把内部文档做成可被 AI 调用的知识库，交付标准就是我们已有的规范；
- 为什么：MCAI 就是最好的案例，方法论已成型；
- 付费：项目制，一次性收费；
- 风险：偏服务，规模受人力限制。

### 方向 C：付费数据/工具（谨慎）

- 做什么：金融、法律、医疗等垂直数据 MCP；
- 为什么：国外已验证付费；
- 风险：数据授权成本高，合规重，不适合现在。

### 方向 D：做「国内 MCP 市场」（不建议）

- 平台层已被巨头占据，且不靠市场本身赚钱；
- 除非有独特流量入口，否则不做。

## 六、判断

- 现在最适合的不是「再造一个平台」，而是**用已有工程能力做垂直工具与交付**；
- 首选 A 与 B：一个做产品化收入，一个做项目制收入，都能反哺 MCAI；
- C 等有数据合作方再做；D 不做。
