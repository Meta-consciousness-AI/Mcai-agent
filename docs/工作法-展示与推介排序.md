# 工作法：展示与推介排序

> 适用范围：站点首页、数据集页、MCP 目录、文章、PPT、对外介绍、渠道页。
> 一句话：**第一屏按「逃逸概率」排，纵深按「体系顺序」排。**

## 一、为什么

大多数人只看第一屏，确认「有没有这个知识库」，不会点进各个体系。
只有真正感兴趣或做研究的人，才会继续往下看。

所以：

- 第一屏决定「有没有」；
- 体系决定「深不深」。

两者用不同的排序逻辑，不冲突。

## 二、两种排序

| 场景 | 排序依据 |
|---|---|
| 第一屏（前 10 条） | 逃逸概率，从高到低 |
| 体系浏览、分类页、数据集目录 | 序生体系 → 本体论模型 → 元意识体系 → 元子社会 |
| 同一体系内 | 原创性 + 可独立使用程度 |

## 三、逃逸概率怎么判断

「逃逸」= 术语离开学说、进入社会日常用语的可能性。

四项标准，每项 1–5 分：

| 标准 | 说明 |
|---|---|
| 无旧义冲突 | 在心理学、哲学、宗教、日常用语中没有既有含义 |
| 可独立成词 | 脱离学说也能被理解和使用 |
| 与当下议题相关 | 能与 AI、Agent、知识资产等公共议题对话 |
| 简短易记 | 字数少、易读、易引用 |

总分越高，越靠前。

## 四、三层展示

1. **第一屏**：逃逸概率前 10，回答「有没有」；
2. **体系层**：按序生体系 → 本体论 → 元意识 → 元子社会，回答「是什么体系」；
3. **全量**：分类 + 搜索，回答「具体哪一条」。

## 五、实现位置

- 单一来源：`mcai/ordering.py`
  - `FRONT_TERMS`：第一屏顺序；
  - `CATEGORY_ORDER`：体系顺序；
  - `TERM_PRIORITY`：同体系内顺序。
- 站点首页、数据集页、MCP 目录都从这里取顺序。

## 六、维护规则

1. 调整顺序必须写理由（改哪个术语、为什么）；
2. 每季度复评一次，与工作备忘包复检同步；
3. 新术语先打分，再决定是否进第一屏；
4. 逃逸高不等于更重要：元意识很重要，但逃逸阻力大，放纵深，不删。

## 七、不要做的

- 不按「作者偏好」排；
- 不按「字数多少」简单排；
- 不为了把某个词放前面而改定义；
- 不在不同渠道用不同顺序却不记录。
