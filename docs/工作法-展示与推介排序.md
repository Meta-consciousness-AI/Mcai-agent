# 工作法：展示与推介排序

> 适用范围：站点首页、数据集页、MCP 目录、文章、PPT、对外介绍、渠道页。
> 一句话：**第一屏按「逃逸概率」排，纵深按「体系顺序」排。**

## 一、为什么

大多数人只看第一屏，确认「有没有这个知识库」，不会点进各个体系。
只有真正感兴趣或做研究的人，才会继续往下看。

所以：

- 第一屏决定「有没有」；
- 体系决定「深不深」。

两者用不同的排序逻辑，不冲突。

## 二、两种排序

| 场景 | 排序依据 |
|---|---|
| 第一屏 | 逃逸概率，从高到低；数量不固定，宁少勿凑 |
| 体系浏览、分类页、数据集目录 | 序生体系 → 本体论模型 → 元意识体系 → 元子社会 |
| 同一体系内 | 原创性 + 可独立使用程度 |

## 三、逃逸概率怎么判断

「逃逸」= 术语离开学说、进入社会日常用语的可能性。

五项标准：

| 标准 | 说明 |
|---|---|
| 无旧义冲突 | 在心理学、哲学、宗教、日常用语中没有既有含义 |
| 可独立成词 | 脱离学说也能被理解和使用 |
| 与当下议题相关 | 能与 AI、Agent、知识资产等公共议题对话 |
| 简短易记 | 字数少、易读、易引用 |
| 不与其他术语重叠 | 与已入选术语不构成近义或包含关系 |

与已入选术语重叠的，不进第一屏（例：序生体已被序生智能体覆盖；元识与元知二选一，选了元知）。

### 当前第一屏（7 条，2026-11-15）

| 序 | 术语 | 判断 |
|---:|---|---|
| 1 | 序生 | 原创、无旧义、统领模型 |
| 2 | 序生智能体 | 原创、与 AI Agent 时代直接相关 |
| 3 | 元网 | 原创、可独立成词 |
| 4 | 元意识 | 学说名，公共曝光度高 |
| 5 | 观测创造实在 | 短语完整，但与量子观测者效应有混淆 |
| 6 | 元知 | 对应「元知识」，与知识资产议题直接相关 |
| 7 | 元子 | 与「原子」易混，放末位 |

## 四、案例：为什么不把「一体多面」立为术语

**背景**：第一屏想放一条本体论，候选人「一体多面」很合适。

**核查**：

| 判断项 | 事实 | 结论 |
|---|---|---|
| 独立定义 | 只出现在「本体」定义里，是模型名 | 不满足 |
| 独立出处 | 与「本体」同一句原文 | 不满足（重复） |
| 独立关系边 | 无，不是节点 | 不满足 |

**决定**：不新增。

**理由**：

1. 术语是核心工作，不能为了展示而增加；
2. 两条词条共用同一出处，违背去重与出处原则；
3. 会稀释本体论的结构（一个本体 + 九个面，是完整设计）。

**推论**：本体论暂不进第一屏，这是正确结果，不是缺口。
本体论是分层模型，十个词条是内部构件，逃逸概率本身低。

**原则**：**不为眼前的事，改核心的事。**

## 五、三层展示

1. **第一屏**：逃逸概率前 7，回答「有没有」；
2. **体系层**：序生体系 → 本体论 → 元意识 → 元子社会，回答「是什么体系」；
3. **全量**：分类 + 搜索，回答「具体哪一条」。

## 六、实现位置

- 单一来源：`mcai/ordering.py`
  - `FRONT_TERMS`：第一屏顺序（当前 7 条）；
  - `CATEGORY_ORDER`：体系顺序；
  - `TERM_PRIORITY`：同体系内顺序。
- 站点首页、数据集页、MCP 目录都从这里取顺序。

## 七、维护规则

1. 调整顺序必须写理由（改哪个术语、为什么）；
2. 每季度复评一次，与工作备忘包复检同步；
3. 新术语先按五项标准打分，再决定是否进第一屏；
4. 逃逸高不等于更重要：元意识很重要但逃逸阻力大，它仍在第一屏第 4，因为它是学说名；本体论重要但不进第一屏。

## 八、不要做的

- 不按作者偏好排；
- 不按字数简单排；
- 不为把某个词放前面而改定义；
- 不为填满第一屏而新增术语；
- 不在不同渠道用不同顺序却不记录。
