## 三、换电脑 / 电脑损坏后的恢复步骤

1. 安装 Python 3.12 与 Git；
2. 克隆代码：

```powershell
git clone https://gitee.com/Meta-consciousness-AI/Mcai-agent.git
cd Mcai-agent
```

3. 解压备份，把以下内容复制回项目：

```
data/                 → 项目根目录
config/corpus.json    → config/
config/llm.json       → config/（如存在）
dist/                 → 项目根目录（可选，能重建）
_source_docs/         → 原始 Word，另存到 E: 或文档目录
```

4. 安装依赖并验证：

```powershell
pip install -e .
python -m mcai validate
python -m unittest discover -s tests
```

5. 重建站点：

```powershell
python tools/build_site_from_kb.py
```

6. 重新配置发布凭证：PyPI token、GitHub/Gitee 凭证、CloudBase 控制台登录。

## 四、日常备份节奏

- **每次改动**：`git add` → `commit` → 推送 Gitee（GitHub 能通就一起推）；
- **每周**：把 `data/kb.json`、`config/corpus.json` 复制到 OneDrive；
- **每月**：生成一次完整 zip，保留最近 3 份；
- **每次发布**：确认 PyPI / 静态站点 / 云托管都已更新。

## 五、注意事项

1. 不要把 token、密钥写进仓库；
2. 备份 zip 含访问日志（IP），只放私有云盘，不要公开分享；
3. GitHub 网络不稳定时，以 Gitee 为准；
4. CloudBase 控制台、PyPI、Zenodo 的账号凭证不在备份里，需要自己保存；
5. 只依赖云端发布物不够：发布物是“已发布版本”，不是最新工作状态。
