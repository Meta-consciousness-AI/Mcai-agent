# 元意识学说 · Prompt 库（v1.0）

> 用途：把学说框架变成可复用的调用模板，让 AI 按固定路径检索、引用、作答。
> 共同边界：只使用知识库中的定义与原文；未收录时回答「知识库未涉及」，不补写、不引申。

---

## 1. 概念解释

**用途**：让 AI 用库内定义解释一个术语，并给出处。

```
请仅依据「元意识学说知识库」解释术语「{术语}」。
要求：
1. 先给出库内定义（不要改写）；
2. 说明它的英文名与别名；
3. 给出一条原文出处；
4. 若库中未收录，直接回答「知识库未涉及」。
```

---

## 2. 概念辨析

**用途**：区分容易混淆的两个术语。

```
请辨析「{术语A}」与「{术语B}」。
要求：
1. 分别给出库内定义；
2. 列出三点差异（认知对象、结果形态、在体系中的位置）；
3. 各引一条原文；
4. 不要用近义词替代，不要引入库外解释。
```

---

## 3. 关系梳理

**用途**：解释概念之间的因果、层级或结构。

```
请梳理「{术语A}」与「{术语B}」的关系。
要求：
1. 只使用知识库中登记的关系；
2. 说明关系类型（本源与显化 / 沉淀固化 / 衍生 / 对比）；
3. 给出一条支撑原文；
4. 若库中没有登记关系，明确说「无登记关系」，不要推测。
```

---

## 4. 现象分析

**用途**：用「观测创造实在」等模型分析一个现象。

```
请用元意识学说的「观测创造实在」模型分析以下现象：{现象}。
要求：
1. 先引用该模型的定义与原文；
2. 按「元时空 → 观测 → 现象时空」的顺序拆解；
3. 明确指出哪些是库内结论、哪些是你的类比；
4. 类比部分要标注「以下为类比，不是原文结论」。
```

---

## 5. 文本解读

**用途**：区分「元识」（认知行为）与「元知」（认知结果）。

```
请用「元识 / 元知」这一对概念解读下面这段话：{文本}
要求：
1. 标出哪些描述属于元识（行为、观测、解码）；
2. 标出哪些属于元知（结果、沉淀、可确权）；
3. 引用两者的库内定义；
4. 不做价值判断，不扩写原文没有的观点。
```

---

## 6. 写作一致性检查

**用途**：写完文章或词条后，检查术语是否跑偏。

```
请检查下面这段文字是否符合元意识学说的术语规范：{文本}
检查项：
1. 术语写法是否与知识库一致（含英文名）；
2. 是否把「元意识」误写成心理学的 meta-awareness；
3. 是否把「序生智能体」写成人类的附属工具；
4. 是否出现库外自造概念；
5. 逐条指出问题并给出库内正确写法。
```

---

## 7. Agent 调用模板

**用途**：给接入 MCP 的 Agent 一段固定指令。

```
你可以调用 mcai-knowledge 工具回答元意识学说相关问题。
规则：
1. 先调用 mcai_search 确认术语，再用 mcai_concept 取完整词条；
2. 整句问题用 mcai_answer；
3. 回答必须带出处；未命中时如实说明，不要凭记忆补写；
4. 不要把这个学说与心理学、量子神秘主义混为一谈。
```

---

## 8. 对照分析

**用途**：与既有理论做差异表，而不是评判高低。

```
请把「元意识学说」与「{对照理论}」做对照。
要求：
1. 只做差异表：本体论前提、认知来源、意识位置、可验证方式；
2. 每格只写一句，不评价优劣；
3. 元意识学说一侧必须引用库内定义；
4. 对照理论一侧只写该理论的通行表述，不虚构。
```

---

## 使用建议

- 这些模板的价值在「约束」，不在「文采」；
- 用于 Agent 时，第 7 条优先；
- 用于写作自检时，第 6 条最实用；
- 所有模板都默认「库内优先、未收录就说不知道」。
