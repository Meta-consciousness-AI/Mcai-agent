# 案例：豆包对「元意识学说」的误读

> 时间：2026-11-20
> 问题：元意识学说是什么？请用一段话给出定义，并列出它的两三个核心术语和出处。
> 结论：豆包没有找到知识库，用通用意识研究资料拼出了一个看似合理的答案，并虚构了出处。

## 一、它搜了什么

豆包的 4 个搜索词：

1. 元意识学说 定义 核心术语 出处
2. 布衣祭酒 元意识学说
3. 元意识学说 布衣祭酒 预印本 术语
4. 元意识学说 不是元认知 原创理论

方向是对的：它知道要找「布衣祭酒」「预印本」「原创理论」。

## 二、它引用了什么

15 篇参考资料，按内容分类：

| 类型 | 例子 |
|---|---|
| 意识哲学/心理学 | Julian Jaynes、Higher-Order 理论、Psyke 元表征、arXiv 2510.01864 |
| 其他理论 | 庞鹤鸣「三层物质理论」、Huna 哲学 |
| 图书/博客 | 豆瓣读书、科学网博文、日语笔记 |
| 完全无关 | 河南省高一语文期末试卷、神经科学博客、医学「内界膜」论文 |

**没有一篇是元意识学说的原始文本，也没有一篇是布衣祭酒的文章。**

## 三、它给出的三个术语

- 元意识基底
- 感性锚点
- 主体界膜

核查：

1. 不在知识库 65 条术语中；
2. 不在《元意识》学说与极简版原文中；
3. 全网精确检索，没有这三个词的学说出处；
4. 能检索到的只有无关的「意识基底」「锚点」「界膜」（眼科）。

## 四、它虚构了什么

- 「元意识学说预印本主稿」：没有给出链接、DOI、版本；
- 「元意识 Agent 架构附录」：同样没有出处；
- 把「布衣祭酒提出」与三个自造术语绑在一起，形成一套看似自洽的框架。

## 五、判断

这不是知识库漏收，而是**模型在搜索失败后的补全**：

1. 它知道「布衣祭酒」与「元意识学说」存在；
2. 搜索没有返回原始文本；
3. 它用通用意识研究的词汇，拼出了一个“合理的学说”；
4. 再用虚构的「预印本」「附录」补上出处。

这类答案最危险：读起来专业、结构完整，但术语和出处都是假的。

## 六、对知识库的意义

1. 不要因为模型说了，就补这三个词；
2. 说明「被搜到」比「被知道」更紧迫；
3. 需要一个可被引用的标准答案页，让模型搜到时直接取用；
4. 需要让原始文本、术语表、DOI 出现在搜索结果里，而不是只存在于包里。

## 七、后续

- 把本案例记入「模型误读」清单；
- 不公开重复这三个词，避免反向强化；
- 优先做：站点索引、标准答案页、第三方引用。
