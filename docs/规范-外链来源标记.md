# 规范：外链统一带 src

> 目的：任何从外部进入站点的点击，都能说清来源。
> 时间：2026-11-16

## 规则

**所有对外链接，一律带 `src` 参数。**

```
https://mcai-mcp-public-338698-11-1316838521.sh.run.tcloudbase.com/r?src=<来源>
```

站点页面会自动带 `p-<页面>`，不需要手写。

## 命名

| 场景 | src |
|---|---|
| 知乎文章 | `zhihu` |
| 公众号文章 | `gongzhonghao` |
| 掘金 | `juejin` |
| 微博 | `weibo` |
| 其他平台 | 平台英文名小写 |
| DOI 跳转（以后） | `doi-zhihu` 等 |
| 测试 | `diag-test`（用完删除，不长期保留） |

只允许小写字母、数字、连字符、下划线，最长 64 字符。

## 为什么

- CloudBase 日志里 `src=unknown` 说明链接没带参数，来源不可归因；
- 2026-11-16 审计：7 天 7 条浏览，其中 4 条 unknown，等于白丢信息；
- 带上 src 后，能对比「平台阅读」与「站内点击」，判断真实转化。

## 执行清单

- [ ] 文章定稿时检查所有站内链接
- [ ] 平台版本（知乎/公众号/掘金/微博）分别用对应 src
- [ ] 发布前用无痕窗口点一次，确认日志出现对应 src
- [ ] 不在公开材料里承诺「点击量」，只说来源可追踪
