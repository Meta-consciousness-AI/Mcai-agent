# 复现案例：道德经（定义分层验证）

> 目的：验证 V1.1 新增的「定义分层」规则——无定义句的文本，`definition` 保留原文句，`editor_note` 单独放编者释义。

## 一、语料

- 文本：《道德经》八十一章原文（公共领域，通行直译本）；
- 来源：公开网页 `chinesebooks.github.io`「道德经直译」，只取原文，剔除直译；
- 规模：81 章、约 7,000 字；
- 工作区：`workspaces/daodejing/`。

## 二、做法

1. 选 10 个核心术语，每个配一句原文（`definition`），逐字可核验；
2. 每个术语另写一句 `editor_note`，明确标注「编者注」，与原文分开；
3. 全部 10 条标记 `definition_type = "editor"`；
4. 人工补英文名、四类分类与 7 条关系；
5. 构建：`mcai build --home workspaces/daodejing`。

## 三、结果

| 指标 | 元意识 | 孙子兵法 | 荀子正名 | 道德经 |
|---|---|---|---|---|
| 概念 | 64 | 13 | 12 | **10** |
| 问答 | 122 | 17 | 5 | 8 |
| 关系 | 270 | 6 | 9 | 7 |
| 引文核验 | 55/55 | 13/13 | 12/12 | **10/10** |
| 定义类型 | quote | quote | quote | **editor** |

验证点：

- `mcai_answer("什么是道")` 返回 `definition_type = "editor"` 与独立 `editor_note`；
- 词条页显示「编者释义（非原文）：编者注：……」，与原文定义分区呈现；
- MCP 词条返回同样两个字段。

## 四、这一轮暴露的问题

| 问题 | 表现 | 处理 |
|---|---|---|
| 原文标记与正文同行 | 第 4 章「【原文】 道冲……」与标题同一行，按行解析得到空章 | 改为正则跨行截取 |
| 引文与原文标点不一致 | 「少私寡欲。」原文实为「少私寡欲，」 | 引文按原文截断，不补句号 |
| **版本差异** | 「见素抱扑」与通行本「见素抱朴」、「水利万物」与「水善利万物」不同 | 按所据版本逐字引用，不做「更正」 |

第三条不是缺陷，而是必须记录的事实：**同一经典的不同版本，字句不同。**

## 五、结论

1. **定义分层可用**：原文句与编者释义在数据、接口、页面三层都分开了；
2. **引文必须逐字**：不能按「常见版本」改字，否则核验失败或造成版本混淆；
3. **规范需补第五条**：必须在语料层记录**版本**（如「王弼本」「通行直译本」），否则同一术语在不同版本下的引文无法对齐。

## 六、对 V1.2 的建议

- 语料配置增加 `edition` 字段（文本版本、来源、校勘说明）；
- 词条增加 `edition` 或在 `sources` 中记录版本；
- 若同一经典有多版本，允许多条引证并存，不做合并。

## 七、复现命令

```bash
python -m mcai build --home workspaces/daodejing
python tools/verify_citations.py --kb workspaces/daodejing/data/kb.json --config workspaces/daodejing/config/corpus.json
```
