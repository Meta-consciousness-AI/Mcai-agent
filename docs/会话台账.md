# 会话台账

> 规则：新会话的名称、范围、边界由主会话 `mcai-knowledge` 决定；专项会话不自行开新会话。
> 命名规范：`mcai-knowledge-<domain>`，见 `docs/工作法-会话管理.md`。
> 上限：同时活跃不超过 3 个（主会话 + 最多 2 个专项）。

| 会话名 | 类型 | 范围 | 状态 | 备注 |
|---|---|---|---|---|
| `mcai-knowledge` | 主会话 | 重大问题、方向决策、对外口径、最终裁定 | 运行中 | 不承担执行 |
| `mcai-knowledge-platform` | 专项 | MCP 注册表 0.4.3、扣子简介、Bing 跟进 | active | 2026-11-22 开；Bing 11-25 后复查看是否 paused |
| `mcai-knowledge-content` | 专项 | N08 下一轮问答/关系审校、内容困惑清单 | planned | 主会话批准后开；完成后 closed |
| `mcai-knowledge-release` | 专项 | 打包、发布、部署、回滚 | merged | 并入 `ops` 或 `platform`，不单开 |
| `mcai-knowledge-search` | 专项 | Bing / Google / 百度 / AI 搜索可见性 | merged | 并入 `platform`，不单开 |
| `mcai-knowledge-theory` | 专项 | 理论辨析、本体论、概念体系 | paused | 暂不单开；重大问题回主会话 |
| `mcai-knowledge-ops` | 专项 | Git 卫生、备份、监控、日常维护 | closed | 2026-11-22 开并关闭；提交 `ace3fca`；Gitee 未推（本机无凭证） |

## 启动规则

1. 主会话先定：名称、范围、边界、验收；
2. 专项会话第一句读 `HANDOFF.md` + `docs/待办.md` + `docs/工作原则.md`；
3. 专项会话只做范围内的事，不自行扩权；
4. 需要再开新会话时，回报主会话定名；
5. 阶段结束，专项会话更新 HANDOFF 的相关条目，主会话做最终裁定。
