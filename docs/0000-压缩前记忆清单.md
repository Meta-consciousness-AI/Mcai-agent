## 五、不能忘的失败与教训

1. **魔搭 Hosted**：校验能过，但没有可用托管资源；最后要账号级 RAM 授权，停止。
2. **扣子→豆包**：渠道已下线，扣子用户不等于豆包用户。
3. **下载量不等于用户量**：PyPI 下载高，真实调用接近 0。
4. **源库失步**：11-19 docx 编辑后 KB 未重建；`built_at` 补丁让它看起来新；校验只查库内自洽，不查源库一致。
5. **作者补充只写 KB**：广义元知没有回写可重建源，重建会丢。
6. **单术语文章**：元网短文写完但不发布；内容价值不够单独成文。
7. **平台扩张**：讯飞、千帆、百炼、魔搭 Hosted 均不投入；不要因窗口期焦虑重复试错。
8. **force push**：`deploy/push-gitee.ps1` 曾是 `push --force main`，危险；Gitee 只用 `master`。
