# 公网部署与「被调用」方案

> 目标：让不在本机的 AI / Agent 能访问元意识知识库。
> 分两件事：**部署**（技术，几天内可完成）和**被调用**（生态，取决于别人是否把你放进工具列表）。

---

## 一、三种部署形态

| 形态 | 适用 | 成本 | 时间 | 稳定性 |
|---|---|---|---|---|
| **A. 隧道**（cloudflared） | 演示、短期试用 | 免费 | 1 小时内 | 依赖你的电脑开机 |
| **B. 云主机 + 域名 + HTTPS** | 长期对外 | 30–60 元/月 + 域名 | 半天～1 天（备案另计） | 7×24 |
| **C. 托管平台**（容器平台/MCP 托管） | 免运维 | 免费档～低月费 | 2–4 小时 | 取决于平台 |

推荐路径：**A 验证 → B 长期**。C 作为备选。

---

## 二、A. 隧道（最快）

```powershell
# 1. 安装（一次性）
winget install --id Cloudflare.cloudflared

# 2. 生成令牌
python -m mcai token

# 3. 启动服务 + 隧道
.\deploy\cloudflared.ps1 -Port 8787 -Token <令牌>
```

脚本会打印 `https://xxxx.trycloudflare.com`，然后：

```bash
python -m mcai set-url https://xxxx.trycloudflare.com
python -m mcai doctor --url https://xxxx.trycloudflare.com --token <令牌>
```

**耗时**：首次约 30–60 分钟（下载、配置、验证）。
**限制**：地址每次重启变化；电脑必须开着；免费隧道有速率限制。

## 三、B. 云主机（长期）

### 0. 前置决策

| 决策 | 说明 |
|---|---|
| 机房位置 | 国内（需 ICP 备案，1–3 周）／ 海外（免备案，访问可能不稳） |
| 域名 | 可选；用 IP + 自签证书不推荐 |
| 规格 | 1 核 1G、20GB 足够（知识库很小） |

### 1. 服务器准备（30 分钟）

```bash
# Ubuntu 22.04
apt update && apt install -y python3 python3-pip caddy ufw
ufw allow 22,80,443/tcp
```

### 2. 部署代码（30 分钟）

```bash
mkdir -p /opt/mcai && cd /opt/mcai
# 用 scp/rsync 上传项目，或 git clone
python3 -m pip install .
mcai init .            # 若还没有配置
# 放入语料，或直接上传 config/ 与 corpus/
mcai build
```

### 3. 令牌与服务（20 分钟）

```bash
export MCAI_TOKEN=$(python3 -c "import secrets; print(secrets.token_urlsafe(24))")
echo "$MCAI_TOKEN"    # 记下来

sudo cp deploy/mcai.service /etc/systemd/system/mcai.service
# 编辑：WorkingDirectory、User、Environment（MCAI_HOME / MCAI_TOKEN）
sudo systemctl daemon-reload
sudo systemctl enable --now mcai
```

服务只监听 `127.0.0.1:8787`，由 Caddy 反代（不要把 8787 直接暴露）。

### 4. HTTPS 反代（20 分钟）

`/etc/caddy/Caddyfile`：

```
kb.example.com {
    reverse_proxy 127.0.0.1:8787
}
```

```bash
systemctl restart caddy
```

Caddy 会自动申请证书。

### 5. 指向新地址（5 分钟）

```bash
mcai set-url https://kb.example.com
mcai build
mcai doctor --url https://kb.example.com --token $MCAI_TOKEN
```

### 6. 加固（1–2 小时）

- 令牌只走 `Authorization` 头；
- 限流保持开启（默认 60 次/分钟/IP）；
- `/api/rebuild`、`/api/v1/stats`、`/api/v1/gaps` 仍只允许本机；
- 每日备份 `backups/`（快照已内置）；
- 日志轮转（`data/access.log`）；
- 监控：外部探针定时打 `/api/v1/health`。

**总耗时**：不含备案约 **4–8 小时**；含备案 **1–3 周**。

## 四、部署完，其他 AI 会主动来调用吗？

**不会自动发生。** 这是最需要说清楚的一点。

AI 不会"浏览互联网找 API"。它只会调用**已经被注册进它的工具列表**的东西。所以真实链路是：

```
你上线
  → 被目录/注册表收录
  → 开发者或平台看到并集成
  → 模型在会话里调用
```

中间每一步都需要**别人采取动作**。你能做的是降低别人的动作成本。

### 为什么「主动」是伪命题

| 你以为的 | 实际的 |
|---|---|
| AI 搜到你的 API 就调用 | AI 只用平台预置的工具 |
| 部署完就有人用 | 部署完只是"可用"，不是"被用" |
| 内容好就会被发现 | 内容好只是"值得被用" |

## 五、让其他 AI 调用的五条路径

### 路径 1：进入 MCP 生态（最直接）

- 把 MCP server 发布成可安装包（npm / PyPI）；
- 提交到 MCP 注册表与目录（官方 registry、Smithery、Glama、mcp.so、awesome-mcp-servers 等，以实际开放情况为准）；
- 提供 `server.json` 与一行安装命令；
- 目标：开发者在 Claude Desktop / Cursor / Cline 里能直接装上。

**耗时**：发布 1 天；审核 1–3 天；**被采用：数周到数月**。

### 路径 2：被平台集成为插件

- Coze / Dify / 豆包 等平台的插件市场；
- 需要开发者账号、审核、可能的资质；
- 一旦进入，平台上的所有 Agent 都能挂载。

**耗时**：申请与审核 1–4 周，取决于平台。

### 路径 3：进入训练/检索语料

- 把数据集发布到 HuggingFace / ModelScope / GitHub；
- 用开放许可，方便下游直接使用；
- 目标：被 RAG 系统或微调流程收录。

**耗时**：发布 1 天；被收录不可控。

### 路径 4：让内容出现在 AI 会抓取的地方

- 公开站点 + Schema.org + `llms.txt` + sitemap；
- 高质量 FAQ、术语页、论文预印本；
- 目标：搜索引擎与 AI 爬虫能读到。

**耗时**：持续数月，效果渐进。

### 路径 5：被具体的人集成

- 把接入文档发给 5–10 个做 Agent 的开发者/团队；
- 提供示例代码与免费额度；
- 目标：先有几个真实调用方，再谈规模化。

**耗时**：取决于人脉与商务。

## 六、30 / 60 / 90 天行动清单

### 第 1–30 天：可用

- [ ] 隧道上线，`doctor` 全绿
- [ ] 域名 + 云主机（如决定长期）
- [ ] MCP 包发布（PyPI/npm）
- [ ] GitHub 仓库公开（代码 + 数据集 + 文档）

### 第 31–60 天：可见

- [ ] 提交 2–3 个 MCP 目录
- [ ] 数据集上 HuggingFace / ModelScope
- [ ] 站点被搜索引擎收录
- [ ] 找 3–5 个开发者试用，收集调用日志

### 第 61–90 天：可用性验证

- [ ] 至少 1 个非关联第三方调用
- [ ] 抽检 baseline vs grounded，确认回答质量
- [ ] 根据调用日志补齐缺口（gaps）
- [ ] 决定是否申请平台插件

---

## 七、度量：怎么知道有没有被调用

| 指标 | 来源 | 目标 |
|---|---|---|
| 外部调用数 | `data/usage.jsonl`（非本机 IP / 非自检 UA） | >0 |
| 独立调用方 | 日志里的 UA / client 标识 | ≥1 |
| 命中率 | `mcai stats` 的 hit_rate | >70% |
| 缺口问题 | `mcai gaps` | 逐周下降 |
| 数据集下载/派生 | HuggingFace / GitHub | 有增长 |

---

## 八、结论

- **部署**：技术上一两天能完成，成本可控；
- **被调用**：不是技术问题，是生态问题，周期以月计；
- **"主动"**：不会凭空发生，只能是"被别人注册进工具列表"；
- **最现实的第一步**：把 MCP 包发出去 + 找 3–5 个开发者真实接入，而不是等 AI 自己找上门。
