# 工作法：经典自建标点与校勘

> 时间：2026-11-19
> 问题：自己标点、自己分段，能不能规避经典入库的版权风险？能不能推广到其他经典？

## 一、能解决什么

自建标点与分段，能解决的是**「复制现代点校本的标点、分段」这一类风险**。

原因是：古籍原文是公版，但现代整理者加的标点、分段、校勘记可能构成演绎作品。自己从公版底本重新标点，就不涉及复制这部分。

## 二、不能解决什么

### 1. 底本与校勘的选择

- 如果底本用的是某出版社的**整理本**（带校勘、注释），即使重新标点，仍在使用他们的校勘成果；
- 异文的选择（哪字从底本、哪字从简本）本身可能体现现代整理者的判断；
- 正确做法：底本用**公版影印本**（宋本、古本、清人注本），校勘自己做。

### 2. 注释、译文、导读

- 这些是现代作品，必须自己写；
- 引用他人注释需授权或控制在适当引用范围。

### 3. 数据库与网站条款

- ctext 明确禁止批量抓取，且只允许非营利学术使用；
- 维基文库是 CC BY-SA 4.0，与我们的 CC BY-NC-SA 有 SA 冲突；
- 不能把「公版原文」当成「可以随便抓的文本」——抓取行为本身可能违约。

### 4. 影印与图片

- 影印本、书影可能涉及版式设计或扫描件的权利；
- 用影印本做校对可以，直接分发扫描页要谨慎。

### 5. 巧合相似

- 清晰的句子，谁标都一样；自建标点后仍可能与某现代点校本高度相似；
- 这时靠的是**独立完成的证据**（凡例、校勘记、决策日志），而不是「看起来不一样」。

## 三、正确做法（五步）

1. **选底本**：公版影印本，记录版本、藏地、影印来源；
2. **定凡例**：标点原则、分段原则、异文处理、存疑标记；
3. **先独立标点**：不看现代点校本，先按文义、语法、韵脚、旧注断句；
4. **再对校**：与简本、武经本、类书引文对校，记校勘记；确需参考现代点校本时，注明「参考某本」，不整段照搬；
5. **出档案**：凡例 + 校勘记 + 存疑表 + 决策日志 + 版本哈希。

## 四、能不能推广到其他经典

能，但难度不同。

| 经典 | 可行性 | 难点 |
|---|---|---|
| 《孙子兵法》 | 高 | 十三篇约六千字；异文集中在少数句；宋本可作底本 |
| 《道德经》 | 中 | 王弼本、帛书甲/乙、郭店简差异大；八十一章分章是传统但各家不同；异文极多 |
| 《荀子·正名》 | 中高 | 可用王先谦《荀子集解》（公版）作底本；单篇篇幅可控 |
| 其他先秦经典 | 视文本而定 | 有公版注本（如十三经注疏）就好办；只有现代整理本的，难 |

### 《道德经》的具体建议

- 底本：王弼注本（公版）；
- 对校：帛书甲、乙本，郭店楚简；
- 分章：沿用八十一章，但在凡例中说明分章依据；
- 异文：出校记，不混入正文；
- 预期工作量：比《孙子兵法》大得多。

### 《荀子·正名》的具体建议

- 底本：王先谦《荀子集解》（公版）；
- 对校：其他清人注本；
- 单篇处理，先做《正名》一篇。

## 五、残余风险（这套流程也消不掉）

必须说清楚：**这套流程能降低风险，不能把风险降到零。**

| 残余风险 | 为什么消不掉 | 应对 |
|---|---|---|
| 影印本本身的权利 | 某出版社的影印本可能涉及版式、扫描件权利；图书馆影像也有使用条款 | 选开放影像或明确许可的底本，记录来源与条款 |
| 校勘记引用现代点校本 | 参考可以，但大段抄其校勘记仍可能侵权 | 只引用具体异文并注明，不复制整段校记 |
| 巧合相似 | 短文本、清晰句子，独立标点也可能与某现代点校本高度相似 | 保留独立完成的过程档案；必要时做相似度比对 |
| 诉讼成本 | 即使有理，被诉也要花时间与钱 | 控制规模、保留证据、必要时咨询律师 |
| 注释与译文 | 若参考他人，仍可能侵权 | 全部自写；引用控制在适当范围 |
| 数据库条款 | 从 ctext 等抓取可能违约，即使文本公版 | 不用爬虫，走许可渠道或自建 |
| 学术规范 | 采用了某学者的校勘结论却不注明 | 校记中注明「某说」 |
| 质量错误 | 自建标点也可能断错 | 专家复核、存疑标记、公开勘误 |
| 跨境法律差异 | 中国、美国、欧盟标准不同 | 对外发布时注明许可与来源；商业化前做尽调 |

结论：**这套流程是「把最大的风险拿掉」，不是「没有风险」。**

## 六、结论

- **自建标点能规避「标点/分段复制」的风险，不能规避全部风险**；
- 底本、校勘、注释、抓取条款，仍要单独处理；
- 方法可以推广到《道德经》《荀子》和其他经典，但工作量与异文复杂度不同；
- 最稳的顺序：先《孙子兵法》做样板，跑通凡例与校勘记，再复制到其他经典。
