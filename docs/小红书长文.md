# AI 总把「元意识」理解错，于是我们做了个资料库

很多人问 AI：元意识是什么？

它大概率会答成心理学的 meta-awareness——对自身认知的觉察。这个答案不算错，只是不是我们要说的那个元意识。

Meta-Consciousness Theory 是一套新的原创学说。模型遇到它时通常有三种反应：没听说过、用同名概念替换、给出一段似是而非的混合表述。第三种最难发现，因为读起来很像。

我们的做法不是让模型记住，而是把学说整理成一套可检索、可引用、可回查的资料：每个术语、每条定义、每句原文出处，都变成机器能读的结构。

听起来简单，做起来踩了几个很具体的坑。

一、出处要精确到字符，不能只写章节

最早的版本只记「文档 + 章节 + 原句」。上线后发现引文核验通过率只有 83.6%。

原因很土：Word 里有大量手动换行，同一页被拆成多个段落，位置号重复，索引互相覆盖。

后来给每条出处补上字符起止位置，并给拆分的段落加序号。改完之后，55 条语料的出处全部逐字命中。

这件事让我们确定一条原则：没有字符区间的出处，不能算可回查。

二、术语形态不能按现代汉语假设

做第二份语料时用了《孙子兵法》，结果「五事」「九地」两个词被丢弃——程序把「中文数字开头」当成了列表编号。

做第三份语料时用了《荀子·正名》，「性」「情」「名」「辞」八个单字术语全部丢失——规则要求术语至少两个字。

两次都是规则误杀，不是语料问题。

最后的处理：只拒绝「数字 + 分隔符」的编号行，允许「五事」这种术语；单字术语也允许，但必须人工登记。

三、没有定义句的文本，必须分层

《道德经》里几乎没有「X 者，Y 也」这样的定义句。任何「定义」都是后人的解释。

如果直接写「道：宇宙的本源」，就是把注疏当原文。

我们的处理是把定义拆成两层：原文归原文，编者理解单独标注。接口、页面和数据集三处都分开呈现，不能混。

这一点看起来只是字段设计，实际决定了这套库能不能被信任。

四、不同版本不是冲突

同一部经典的不同版本，字句本来就不一样。比如《道德经》有的版本写「见素抱扑」，通行本写「见素抱朴」。

早期逻辑会把这种差异判成「冲突」，要求人工裁定。但这不是错误，是版本事实。

后来给每条出处记录版本信息，版本之间的差异并存可查；只有同一版本内出现明显分歧，才需要人工裁定。

结果

主库现在有 64 个概念、122 组问答、270 条关系、213 条原文引证。

另外用《孙子兵法》《荀子·正名》《道德经》三份公共领域文本做了复现，分别得到 13、12、10 个概念，引文核验都是 100%。

复现暴露的规则问题，比主库本身更有价值。

现在的状态

老实说，这套东西才刚刚开始。

GitHub 还没有 Star，Zenodo 的下载量、智能体的使用量、远程 MCP 的调用计数，也都还没什么量。

我们认为，可能是还没把这套东西放到想用它的人面前。
