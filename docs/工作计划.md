# 工作计划

> 只放「已决定要做」的项目；想法与等待项在 `docs/工作备忘包/`。
> 每个项目做完一项再开下一项，不并行铺开。

## P1 引文验证器（已完成，待随 0.3.6 发布）

- 目标：输入任意知识包，输出引文核验报告（对原文、逐字、字符区间）；
- 基础：`tools/verify_citations.py` 已有，四语料核验 100%；
- 产物：通用 CLI + 报告格式 + 使用说明；
- 预估：1–2 周；
- 验收：现有知识库 66 条来源、55 条语料全部逐字命中，118 项测试通过。
- 产物：`mcai/verify.py`、`mcai-verify` 入口、`tests/test_verify.py`、`docs/引文验证器.md`

## P2 评测基准包（进行中）

- 目标：把数据集包装成「引用忠实度」评测基准（考卷 + 标准答案 + 评分脚本）；
- 基础：每条定义带出处与字符区间；
- 产物：benchmark 说明、样例、评分脚本；
- 预估：2–3 周；
- 前置：P1 完成（复用核验逻辑）。

## P3 工具链化 CLI（排队）

- 目标：一条命令跑完六步（init → extract → validate → build → mcp → package）；
- 基础：`mcai build` / `mcai mcp` / `doctor` 已有；
- 产物：`mcai init` / `mcai validate` / `mcai package`；
- 预估：3–4 周；
- 前置：P1、P2 的经验。

## 原则

- 不做「看起来该做」的项目；
- 每个项目先小样验证，再扩；
- 完成一个再开下一个；
- 外部条件不足的，放 `工作备忘包/待条件成熟.md`。
