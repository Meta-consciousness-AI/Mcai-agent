## 我们的指令是

请 `0002` 删掉 `mcai/pipeline.py` 里的旧 IndexNow 写 key 逻辑（现 L159–163 附近）：

```python
key_file = root / "data" / "indexnow-key.txt"
if key_file.exists():
    key = key_file.read_text(encoding="utf-8").strip()
    if key:
        (root / "dist" / f"{key}.txt").write_text(key, encoding="utf-8")
```

**为什么删**：key 的唯一来源现在是 `config/indexnow.json`，写 key 的唯一入口是 `tools/submit_indexnow.py --write-key`。留着这段，任何机器上只要残留 `data/indexnow-key.txt`，构建就会悄悄生成一个**过期 key 文件**，IndexNow 校验随之失败（403），而且从构建日志上完全看不出来。不做兼容、不保留开关。

要做的事：

1. 删除该段，连同因此变成未使用的变量与导入（`root`/`Path` 若仍被其它代码用到则保留，别误删）；
2. **先查 `tests/` 里有没有覆盖这个行为**：若有，连带删掉或改成「构建不再写 key 文件」的断言；没有就说明一句；
3. 顺手查 `git grep indexnow-key`，把文档里仍指向旧机制的说明改成指向 `config/indexnow.json` 与 `--write-key`（第五批已改过一批，这里只补遗留）。
