# 研判：显性条件约束

> 时间：2026-11-17
> 结论：在显性条件不足时，不做出击型机构合作。

## 一、什么叫显性条件

机构客户在接触前能直接看到的：

- 公司知名度与品牌；
- 团队规模与技术背书；
- 办公场所、资质、案例；
- 过往项目与客户名单；
- 融资或背景。

## 二、我们的现状

| 项 | 我们 | 行业中较好的机构 |
|---|---|---|
| 品牌 | 个人项目起步 | 有多年积累 |
| 团队 | 小 | 几十到几百人 |
| 办公 | 无对外场所 | 有 |
| 资质 | 无投标/认证资质 | 齐全 |
| 案例 | 自建样本 | 大量客户案例 |

判断：**我们的显性条件明显弱于同行。**

## 三、推论

1. 冷邮件联系出版社、教育机构、文化项目，成功率极低；
2. 即使对方有兴趣，也会因「看起来不像能承接的团队」而止步；
3. 现在出击，消耗的是有限的信用与时间。

**所以：不做出击型机构合作，直到显性条件改善。**

## 四、那我们做什么

转向「积累可信度资产」——让别人先看见凭证，再谈合作。

| 资产 | 作用 | 门槛 |
|---|---|---|
| 同行评议论文 | 学术信用 | 中，需时间 |
| 开源项目 | 开发者信用 | 低 |
| 公开基准/数据集 | 行业参照 | 低 |
| 被引用 | 第三方背书 | 慢 |
| 公开演讲/课程 | 专业形象 | 中 |
| 合作署名 | 机构背书 | 需先有关系 |
| 媒体报道（非软文） | 公众认知 | 需新闻点 |

## 五、判断标准

一条路径是否适合现在做，先问：

> 它需不需要对方先信任我们？

- 需要：暂缓，等显性条件；
- 不需要（靠作品本身说话）：可以做。

## 六、待研究

- 学术发表路径：投哪里、周期、门槛；
- 开源路径：开源什么、怎么被使用；
- 基准路径：谁会用、怎么被引用；
- 演讲/课程路径：什么场合、怎么被邀请。
