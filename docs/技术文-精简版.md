# （标题待定）

Meta-Consciousness Theory 是一套原创学说。模型遇到它时常有三种反应：没听过、用同名概念替换、给出似是而非的混合表述。我把它做成了可被 AI 调用的知识库，这里记几个工程决定。

结构很直接：docx/pdf → 抽取 → 知识库 JSON → 站点 / 数据集 / MCP。核心对象只有四个：概念、问答、关系、引证。

**一、出处精确到字符区间。** 最早只记「文档 + 章节 + 原句」，Word 的手动换行让位置号重复，引文核验只有 83.6%。补上 `char_start` / `char_end` 并区分拆分段落后，55 条出处全部逐字命中。

**二、术语形态要按语料定。** 《孙子兵法》的「五事」「九地」被当成中文编号丢弃；《荀子·正名》的「性」「情」「名」被「至少两字」规则拒绝。改法是只拒绝「数字 + 分隔符」，单字术语人工登记后放行。

**三、没有定义句就分层。** 《道德经》几乎没有「X 者，Y 也」。任何定义都是解释，所以 `definition` 只留原文，`editor_note` 放编者注，接口、页面、数据集三处分开呈现。

**四、版本差异不算冲突。** 有的版本写「见素抱扑」，通行本写「抱朴」，这是版本事实。差异记入 `edition_variants` 并存；只有同一版本内的分歧才判冲突。

结果：主库 64 个概念、122 组问答、270 条关系、213 条引证；另用孙子、荀子、道德经三份公共领域文本复现，引文核验均为 100%。

用起来就两步：

```bash
pip install mcai-knowledge
mcai-mcp
```

MCP 客户端加一段 `command: uvx --from mcai-knowledge mcai-knowledge` 即可；也可以直接请求 HTTP 接口。
