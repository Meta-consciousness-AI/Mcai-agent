# （标题待定）

Meta-Consciousness Theory 是一套原创学说。它不在主流语料里，模型遇到时通常有三种反应：没听说过、用同名概念替换、给出似是而非的混合表述。后两种最难发现，因为读起来很像。我的做法不是让模型记住，而是把它做成可检索、可引用、可回查的数据服务。

结构很直接：docx/pdf → 抽取 → 知识库 JSON → 站点 / 数据集 / MCP。核心对象只有四个：概念、问答、关系、引证，每个概念至少带一条可回查的出处。

**一、出处精确到字符区间。** 最早只记「文档 + 章节 + 原句」，Word 的手动换行让位置号重复，引文核验只有 83.6%。补上 `char_start` / `char_end`、区分被拆开的段落后，55 条出处全部逐字命中，字符区间一致率 100%。没有字符区间的出处，不算可回查。

**二、术语形态要按语料定。** 《孙子兵法》的「五事」「九地」被当成中文编号丢弃；《荀子·正名》的「性」「情」「名」被「至少两字」规则拒绝。两次都是规则误杀。改法是只拒绝「数字 + 分隔符」，单字术语人工登记后放行。

**三、没有定义句就分层。** 《道德经》几乎没有「X 者，Y 也」。任何定义都是解释，所以 `definition` 只留原文，`editor_note` 放编者注，接口、页面、数据集三处分开，避免把注疏当原文。

**四、版本差异不算冲突。** 有的版本写「见素抱扑」，通行本写「抱朴」，这是版本事实。差异记入 `edition_variants` 并存可查；只有同一版本内的分歧才判冲突。

关系也要分层：270 条关系里 246 条是正文共现，默认只返回人工确认的 `core` 与 `derived`，`mention` 需要显式打开，否则关系图基本是噪声。

之所以做成 MCP，而不是再开一个网页，是因为 Agent 需要的是工具，不是另一个需要人点击的界面。

结果：主库 64 个概念、122 组问答、270 条关系、213 条引证；另用孙子、荀子、道德经三份公共领域文本复现，引文核验均为 100%。复现暴露的规则问题，比主库本身更有价值。

用起来两步：

```bash
pip install mcai-knowledge
mcai-mcp
```

MCP 客户端加 `command: uvx --from mcai-knowledge mcai-knowledge`；不想装也可以直接请求 HTTP 接口。
