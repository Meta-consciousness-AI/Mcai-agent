# 发布渠道指标记录

> 目的：用趋势判断「是否被使用」，不用单日数字做决策。
> 自动采集：`python tools/metrics_scan.py`，写入 `data/metrics.jsonl`。
> 需要人工/浏览器补查：Zenodo 浏览与下载、Bing 收录状态、第三方提及。

## 基线

| 日期 | PyPI 7 日下载 | PyPI 30 日下载 | GitHub Star | Fork | Zenodo 数据集（浏览/下载） | Zenodo 预印本（浏览/下载） | Bing |
|---|---|---|---|---|---|---|---|
| 2026-10-31 | 382 | 382 | 0 | 0 | 7 / 0 | 0 / 0 | 已发现未爬取 |

说明：382 次下载集中在 10/29 发布当天，可能包含镜像与扫描服务，不能视为真实用户数。

## 判读规则

| 状态 | 特征 |
|---|---|
| **无人使用** | 下载长期接近 0；无 Star；无第三方提及 |
| **零散使用** | 每周有个位数下载；偶有 Star 或提及 |
| **出现稳定调用** | 连续数周下载增长；Star/引用出现；Zenodo 有下载 |

## 记录节奏

- 每周一 09:00：运行脚本 + 查 Zenodo/Bing，汇报一周变化；
- 每月 1 日 09:00：汇总趋势，写一段结论（无人使用 / 零散使用 / 稳定调用）。
