# 工具链（P3）

> 目标：一条命令跑完「构建 → 校验 → 打包」，让别人也能复用。
> 状态：可用，2026-11-13。

## 命令

```bash
mcai init <dir>     # 初始化工作区（已有）
mcai build          # 语料 → 知识库 → 站点
mcai validate       # 引文核验 + 质量巡检，可进 CI
mcai package        # 导出数据集并打包 zip
mcai all            # 构建 → 校验 → 打包，一条命令
```

## 典型流程

```bash
mcai init my-kb
# 把文档放进 my-kb/corpus/，登记到 my-kb/config/corpus.json
cd my-kb
mcai all
```

产物：

- `data/kb.json`：知识库；
- `dist/`：静态站；
- `dist/dataset/`：数据集文件；
- `dist_pkg/mcai-knowledge-dataset-<version>.zip`：可上传 Zenodo 的包。

## validate 检查什么

1. 每条引文能否定位到语料块；
2. 是否逐字命中；
3. 字符区间是否与引文一致；
4. 人工条目（`origin=curated`）单独计数；
5. 质量巡检：定义、关系、死链、JSON-LD。

退出码：`0` 通过；`1` 有问题。

## package 打包什么

`dist/dataset/` 下的全部文件，加上 `docs/dataset-README.md`（如果存在）。

## 与 P1 / P2 的关系

- P1 的验证器是 `validate` 的核心；
- P2 的评测集可对 `package` 产物做外部评测；
- P3 把两者串成一条流水线。
