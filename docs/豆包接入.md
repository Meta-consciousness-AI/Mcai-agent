# 豆包（桌面版）接入元意识知识库

已验证：豆包 2.31.4 的「工作」模式可以在这台笔记本上执行 PowerShell，并能访问 `127.0.0.1:8787`。
2026-10-19 00:26 的访问日志中出现了对应的 `/api/v1/health` 请求，证明链路打通。

---

## 方式 A：临时调用（每次说一句）

在豆包「工作」模式里直接说：

```
请用 PowerShell 执行下面这条命令，并基于返回结果回答我：

$body = @{ question = "什么是元意识学说" } | ConvertTo-Json -Compress
Invoke-RestMethod -Uri "http://127.0.0.1:8787/api/v1/answer" -Method Post -ContentType "application/json; charset=utf-8" -Body ([System.Text.Encoding]::UTF8.GetBytes($body)) | ConvertTo-Json -Depth 4
```

注意：**不要让豆包用 `curl` 直接带中文**（会返回 HTML 400），用上面的 PowerShell 或 POST 方式。

## 方式 B：固化成技能 / 项目指令

在豆包的「插件·技能·伙伴」或「创建新项目」里，把下面这段作为固定指令：

```
你是元意识学说的知识助手。当用户询问以下任意概念时：
元意识、元态能量、元时空、观测创造实在、现象时空、序生、序生智能体、元识、元知、元灵、元子

必须先查询本地知识库，再作答：
1. 用 PowerShell 执行：
   $body = @{ question = "<用户原问题>" } | ConvertTo-Json -Compress
   Invoke-RestMethod -Uri "http://127.0.0.1:8787/api/v1/answer" -Method Post `
     -ContentType "application/json; charset=utf-8" `
     -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
2. 优先使用返回的 answer 与 context；
3. 引用时保留 citations 中的文档名与章节；
4. 若 type 为 none，如实回答"知识库未涉及"，不要编造；
5. 不要把这套学说与量子神秘主义或心理学 meta-awareness 混为一谈。
```

## 方式 C：MCP（如果豆包提供入口）

豆包安装目录里有 `mcp_helper.dll`，主程序含 `mcpServers` 与「读取 Claude Code 配置」的错误码，
说明它具备 MCP 客户端能力，但入口是否开放取决于版本与模式。

如果「插件·技能·伙伴」或设置里出现 MCP / 导入 Claude 配置，填：

```json
{
  "mcpServers": {
    "mcai": {
      "command": "C:\\Users\\HP\\.dsh\\dsh-runtimes\\dsh-primary-runtime\\dependencies\\python\\python.exe",
      "args": ["-m", "mcai", "mcp", "--home",
               "C:\\Users\\HP\\Documents\\deepseek-harness\\default-workspace\\mcai-agent"]
    }
  }
}
```

MCP 与命令行方式的区别：MCP 下模型能看到工具、遇到相关问题会**自己决定调用**；
命令行方式需要你在提示词里要求它执行。

## 验证是否真的调用了

每发生一次调用，`data/access.log` 会多一行：

- `path` 为 `/api/v1/answer` 或 `/api/v1/health`
- `client` 为 `WindowsPowerShell/5.1...`（豆包通过 PowerShell 发起）
- `ip` 为 `127.0.0.1`

也可以直接看观测台：<http://127.0.0.1:8787/dashboard.html> 的「业务问答」与「高频问题」。
注意：来自豆包的请求目前会被记为「本机」，因为 IP 是回环地址。

---

## 安全提醒

「本地电脑」模式意味着豆包可以在你机器上执行命令。这是能力，也是权限：

- 只在你需要时打开这个开关；
- 不要让它执行你不理解的命令（尤其是删除、安装、改系统设置）；
- 本知识库服务是只读的，不会修改你的文件。

## 方式 B（推荐）：技能包，一次安装，长期生效

技能已做好，位于 `doubao-skill\mcai-knowledge\`（含 `SKILL.md` 与 `bin\query.ps1`）。

安装：

1. 双击项目根目录的 **`安装豆包技能.cmd`**
2. 完全退出豆包（托盘图标右键退出），重新打开
3. 打开「工作」模式 →「插件·技能·伙伴」→ 看是否出现 `mcai-knowledge`
4. 新对话直接问「什么是元意识学说」，**不需要再让它执行命令**

它会自动调用本机知识库，并保留出处。

卸载：`.\deploy\install-doubao-skill.ps1 -Remove`

如果技能列表里没有出现：说明这个版本的豆包不加载用户技能，改用下面的「项目指令」方式。

### 项目指令（备选）

新建项目后，把这段放进项目说明/自定义指令：

```
当用户询问元意识、元态能量、元时空、观测创造实在、现象时空、序生、序生智能体、
元识、元知、元灵、元子等概念时，先执行：

powershell -NoProfile -File "C:\Users\HP\Documents\deepseek-harness\default-workspace\mcai-agent\doubao-skill\mcai-knowledge\bin\query.ps1" -Question "<用户原问题>"

再基于返回的 answer/context 作答，保留 citations 中的出处；type=none 时如实说知识库未涉及。
```
