# 发布「元意识学说」Coze 智能体到豆包

> 目标：让豆包用户搜到、打开即可对话，不需要安装技能。
> 现状：豆包公共技能商店不开放个人自定义技能上架；走 Coze 智能体 → 豆包渠道。

## 已准备好的文件

| 文件 | 用途 |
|---|---|
| `integrations/coze/openapi.json` | Coze 插件定义（OpenAPI 3.0，两个工具） |
| `integrations/coze/prompt.md` | 智能体提示词 |

插件直接调用公网 API，答案实时来自知识库，不是复制旧数据。

## 第一步：注册 Coze

1. 打开 `https://www.coze.cn/`；
2. 用手机号注册/登录；
3. 完成实名认证（发布到豆包通常需要）；
4. 创建一个工作空间，例如「元意识学说」。

## 第二步：创建插件

1. 左侧「资源库」→「插件」→「创建插件」；
2. 名称：`mcai-knowledge`；
3. 描述：`查询元意识学说的术语定义、问答与出处`；
4. 选择「基于 OpenAPI 导入」；
5. 上传 `integrations/coze/openapi.json`；
6. 认证方式选「无需认证 / None」；
7. 导入后检查两个工具：
   - `mcaiAnswer`：POST `/answer`
   - `mcaiSearch`：GET `/search`
8. 在调试区测试 `mcaiAnswer`，问题填 `什么是元识？`；
9. 能返回定义与出处后，保存并发布插件。

## 第三步：创建智能体

1. 左侧「智能体」→「创建智能体」；
2. 名称：`元意识学说`；
3. 简介：`元意识学说的知识助手：术语定义、概念关系与原文出处，只基于知识库回答。`（**2026-11-25 核对**：线上页面用的是这一句，与本文件旧记录不一致；已按「以页面为准」回写，不再改页面）
4. 模型：选豆包系列；
5. 人设与回复逻辑：粘贴 `integrations/coze/prompt.md` 全文；
6. 添加插件：选刚创建的 `mcai-knowledge`；
7. 调试：
   - `什么是元识？`
   - `元识和元知有什么区别？`
   - `序生智能体是什么？`
8. 确认回答带出处、没有编造。

## 第四步：发布到豆包

1. 右上角「发布」；
2. 渠道勾选「豆包」；
3. 填写发布说明，例如：`元意识学说知识库问答 v1.0`；
4. 提交审核；
5. 审核通过后，在豆包搜索「元意识学说」或智能体名称，确认能打开。

## 可见性

- 公开：豆包用户可搜索到；
- 链接分享：只有拿到链接的人能用；
- 私有：仅自己。

要“搜到的人能用”，选公开；不要选私有。

## 测试清单

- [ ] 豆包搜索「元意识学说」能找到；
- [ ] 打开后问「什么是元识」，回答带 p45 出处；
- [ ] 问「元识和元知有什么区别」，能分别回答；
- [ ] 问一个库外问题，回答「知识库未涉及」，不编造；
- [ ] 问「元意识基底」这类不存在的术语，不跟着编。

## 风险与限制

1. 豆包渠道可能要求企业资质或审核，个人账号未必放行；
2. 审核可能对名称、简介、头像有要求，避免夸张承诺；
3. 插件调用公网 API，冷启动可能 30–90 秒，Coze 侧要设足超时；
4. 公开 API 无鉴权，调用量上来后要加限流；
5. 智能体不会进入豆包默认对话，只服务主动搜索/打开的人。

## 如果豆包渠道不放行

退一步：

1. 发布到 Coze 商店/链接；
2. 用 Coze Web SDK 嵌入自己的站点；
3. 回到公开网页问答页方案。
