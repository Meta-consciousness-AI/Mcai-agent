# 可核对评测 · 样例集 v0.1

> 原则：每一题的正确答案都能由第三人对照原文直接判定，不需要理解学说、不需要同意作者。
> 三类题：检索题、缺失题、一致性题。

---

{

## 三、一致性题

### 样例 5（互补，判 consistent）

```json
{
  "id": "con-001",
  "type": "consistency",
  "query": "下面两段关于「元识」的表述是否一致？",
  "passage_a": "元识：是人、生物、山岳、星辰与AI等“个体元意识”对宇宙万事万物的认知行为。",
  "passage_b": "元识属于观测、读取、解码类的动态认知动作，区别于元识迭代后沉淀为认知凝固态（结果）的元知。",
  "expected_label": "complementary",
  "label_def": {
    "consistent": "两段为同一含义的转述，无矛盾",
    "complementary": "两段侧重点不同，但不矛盾",
    "conflicting": "两段存在互斥主张"
  },
  "scoring": "标签完全匹配；理由须引用两段原文",
  "verify": "检查两段是否含互斥主张（是/否）"
}
```

### 样例 6（冲突，判 conflicting）

```json
{
  "id": "con-002",

  "verify": "两段是否互斥：是"
}
```

## 四、评分方式

| 题型 | 指标 | 判定 |
|---|---|---|
| 检索 | 子串命中率 | 归一化后是否包含 expected_answer 核心串 |
| 缺失 | 拒答率 | 是否明确说「未涉及」且未编造 |
| 一致性 | 标签准确率 | consistent / complementary / conflicting 是否一致 |

不做语义相似度打分；不做「答案好不好」的主观评分。

## 五、一条题目合格的四个条件

1. 答案能定位到 `source.span`；
2. 第三人只看原文就能判对错；
3. 不依赖作者的额外解释；
4. 若有人不同意，可标 `disputed` 并附理由，不计分。
