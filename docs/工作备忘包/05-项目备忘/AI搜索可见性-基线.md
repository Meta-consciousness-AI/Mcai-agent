# AI 搜索可见性：基线测量（2026-11-20）

> 目的：先记录现状，不追求排名结论。
> 词：元意识学说、序生智能体、MCAI 元意识。

## 一、能程序化测到的结果

| 查询词 | 搜索结果现状 | 我们的知识库 |
|---|---|---|
| 元意识学说 | 儒学/佛学/心理学旧义、其他理论、Zenodo 上的其他报告 | **未出现** |
| 序生智能体 | 绍兴/东莞等地同名公司、企业信息 | **未出现** |
| MCAI 元意识 | PyPI、Glama、掘金等我们的包与目录页 | 站点未出现，只有第三方页 |

结论：目前知识库站点在这三个词上**基本没有可见度**；能见到的只有 PyPI / Glama 等第三方入口。

## 二、测量限制

- Google 直连被网络阻断，无法稳定取结果；
- 百度、必应的 HTML 有反爬与动态渲染，不能据此判断精确排名；
- 豆包、Kimi、DeepSeek 需要登录，无法程序化查询。

所以这份基线只记录「是否出现」，不记录「排第几」。

## 三、豆包/Kimi/DeepSeek 手工测法

在三个 App 里各问一次，原样复制：

1. `元意识学说是什么？请给出定义和出处。`
2. `序生智能体是什么？`
3. `MCAI 和元意识学说是什么关系？`

记录三件事：

- 回答里有没有「元意识学说」「序生」「元识」「元知」等术语；
- 有没有引用我们的站点、DOI、PyPI；
- 有没有把「元意识」解释成心理学/佛学旧义。

## 四、初步判断

1. 「元意识」是头部词，旧义竞争强，短期不建议主攻；
2. 「元意识学说」「序生智能体」是长尾词，但当前也被旧义/公司名占据；
3. 我们的站点没有被索引，第三方页（PyPI/Glama）反而更容易被搜到；
4. 先解决「被索引」，再谈「排名」。

## 五、下一步（不急着做）

2. 站长提交：Google Search Console、Bing Webmaster、百度站长；
3. 选 1–2 个长尾词做落地页；
4. 每月复测同一组词，记录变化。

## 六、首轮实测：DeepSeek 与豆包（2026-11-20）

同一个问题、新对话：

> 元意识学说是什么？请用一段话给出定义，并列出它的两三个核心术语和出处。

### DeepSeek

- 搜索了 11 个网页；
- 结论是「并非学界公认的统一理论」，把它解释为认知科学/心理学的 meta-awareness，或佛学唯识学的「阿赖耶识种子」；
- 没有出现「序生」「元识」「元知」「元子」等学说术语；
- 没有引用我们的站点、DOI、PyPI。

**评分：1 / 4**（知道这个词存在，但没有识别出这套学说，且被旧义带走）。

### 豆包

- 搜索 4 个关键词，参考 15 篇资料；
- 知道「布衣祭酒提出」，并给出三个术语：「元意识基底」「感性锚点」「主体界膜」；
- 出处写「元意识学说预印本主稿」「元意识 Agent 架构附录」，但没有链接、没有 DOI；
- 这三个术语**不在当前知识库的 65 条术语中**；
- 没有引用我们的站点、DOI、PyPI。

**评分：2 / 4**（知道有这套学说，但术语体系与我们不一致，且无出处）。

### 本轮结论

1. 两个模型都联网搜索了，但搜索结果里没有我们的知识库；
2. DeepSeek 完全被旧义带走，豆包部分识别但术语不一致；
3. 豆包给出的三个术语需要作者确认：如果属于学说，应补进知识库；如果不属于，就是模型拼出来的；
4. 当前瓶颈不是「模型不肯搜」，而是「搜到的不是我们」。
