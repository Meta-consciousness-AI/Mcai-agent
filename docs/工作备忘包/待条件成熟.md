# 待条件成熟

> 来源：第二次综合参考里「方向对、条件不足」的部分。
> 规则：条件满足再拿出来评审，不提前投入。

| 方向 | 缺什么条件 | 触发信号 |
|---|---|---|
| 知识包互认协议 | 第二个真实知识包 | 有人用同一规范做出第二个包 |
| 多版本异文契约 | 古籍多版本语料 | 中华经典项目恢复，或有合作方提供底本 |
| Agent 经验传承层 | 真实需求 | 有 Agent 开发者提出「要继承经验」 |
| 序生智能体评测基准 | 定义与样本 | 有人愿意用这套定义做评测 |
| 跨学说认知翻译器 | 第二个学说库 | 出现第二个独立学说库 |
| 民间思想联邦 | 多作者协作机制 | 有 3 个以上作者愿意按同一规范 |
| 个人认知资产确权 | 独立项目结论 | 个人知识确权项目跑出结论 |
| SaaS / Shopify | 产品与运营能力 | 有真实付费需求 |
| 标准 / 质检中间件 | 企业客户 | 有企业要求按规范清洗数据 |
| 数字文献学基础设施 | 内容与合作 | 有古籍机构合作意向 |

## 不急的原因

- 都需要外部条件，不是我们单方面努力能成；
- 提前做容易变成自嗨；
- 保持记录，等信号出现再评估。
