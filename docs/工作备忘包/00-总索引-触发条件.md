# 00 总索引：暂缓事项与触发条件

> 这是工作备忘包的**唯一权威表**。任何暂缓事项都必须在这里出现，且必须写清「什么条件下重新启动」。
> 没有触发条件的条目，不收。
> **触发条件只是参考，不是开关**：条件出现后仍要先综合研判，再决定做不做、怎么做。
> 复检：每季度一次（30 分钟）；每年一次全面复检（2 小时）。

## 使用方式

1. 新事项暂缓 → 先在表里加一行，再建明细文件；
2. 触发条件必须**可观察**（数字、事件、明确问句），不能写「以后再说」；
3. 复检时只做两件事：更新状态、判断触发条件是否出现；
4. 触发条件出现**不等于启动**：先做一次综合研判——当初的理由是否仍成立、环境里有哪些变量已经变了、这件事的形态是否需要重定；研判通过才转 `docs/工作计划.md` 并标注「已启动」；不通过则把新理由写回本表，改触发条件或转「不开展」。
