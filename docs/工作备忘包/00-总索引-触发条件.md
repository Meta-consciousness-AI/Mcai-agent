# 00 总索引：暂缓事项与触发条件

> 这是工作备忘包的**唯一权威表**。任何暂缓事项都必须在这里出现，且必须写清「什么条件下重新启动」。
> 没有触发条件的条目，不收。
> 复检：每季度一次（30 分钟）；每年一次全面复检（2 小时）。

## 使用方式

1. 新事项暂缓 → 先在表里加一行，再建明细文件；
2. 触发条件必须**可观察**（数字、事件、明确问句），不能写「以后再说」；
3. 复检时只做两件事：更新状态、判断触发条件是否出现；
4. 触发后 → 转 `docs/工作计划.md`，并在本表标注「已启动」。
