# 决定：经典自建标点并入，暂不启动

> 时间：2026-11-19
> 决定人：项目发起人
> 状态：暂缓，不投入

## 一、决定

**不做经典自建标点，也不把三部经典并入 mcai-knowledge。**

## 二、理由

1. 工作原则的第一条是**优先确保元意识学说的传播与传承**；
2. 经典入库即便自建标点，仍有残余风险：影印本权利、校勘引用、巧合相似、诉讼成本、数据库条款、跨境法律差异；
3. 这些不确定性，与「把资源集中在元意识学说」相冲突；
4. 并入带来的好处（方法可迁移的公开证据、古籍流量）是**间接的、可替代的**，不值得用核心工作去换。

## 三、已经做过的评估（留档）

- [风险评估](../评估-经典并入mcai-knowledge的风险.md)
- [好处评估](../评估-经典并入mcai-knowledge的好处.md)
- [自建标点方法](../工作法-经典自建标点与校勘.md)

结论保留：若将来要做，路径是「公版影印底本 + 自建标点 + 凡例 + 校勘记 + 过程档案」，但仍非零风险。

## 四、何时重启

满足以下**全部**条件才考虑：

1. 元意识学说的传播与传承进入稳定状态（例如有持续调用、有机构采用）；
2. 找到**明确许可**的公版底本（开放影像或书面授权）；
3. 有法律意见，或合作方承担版权审查；
4. 有人手专门做校勘与维护；
5. 有真实需求（有人明确要查经典，或合作项目需要）。

缺一条，不启动。

- 论文与学术发表；
