# 品牌图形「元」：暂缓

> 编号：P07
> 状态：暂缓（2026-11-18）
> 结论：主标已定 `MCAI·元`，图形属锦上添花，不急于推进。

## 一、已经确定的

- **主标**：`MCAI·元`（文字，保留中点）；
- 中点不是多余：它分隔拉丁字母与汉字，去掉会连读；
- 图形不与「元」字并排使用，避免重复。

## 二、尚未确定的

图形的三个方向：

| 方向 | 做法 | 适用 | 风险 |
|---|---|---|---|
| 1. 篆体简化 | 小篆「元」减笔、加粗、圆角 | 印章、水印、头像 | 小尺寸易糊 |
| 2. 几何「元」 | 两横 + 两腿（E3 延续） | UI、favicon、页眉 | 需要再调比例 |
| 3. 圆点 + 圆环 | 点（头）+ 圆（始） | 长期品牌资产 | 初始辨识度低 |

## 三、已完成的研究

- 字形演变：甲骨（人形+头点）→ 金文 → 西周加横 → 小篆（一+兀）→ 楷书；
- 外部参考：比亚迪篆体「元」、元气森林单字策略、陈楠甲骨文设计字库、元人动画「O=零/圆」、元一文化「元+圆」；
- 草图：`docs/brand/` 下的 A–F、E2、E3 与组合对照图。

## 四、触发条件

出现以下任一情况，再启动：

1. 需要做**头像 / favicon / 应用图标**；
2. 需要**印刷品**（名片、信纸、封面、展板）；
3. 需要**线下展陈或门头**；
4. 有人主动问「你们的标志是什么」；
5. 平台要求上传品牌图标。

在此之前，统一用文字标 `MCAI·元`。

## 五、重启后的第一步

1. 从方向 1 与方向 2 各画一版；
2. 做 32px、反白、单色测试；
3. 与文字标组合，确认间距；
4. 再决定是否进入方向 3。
