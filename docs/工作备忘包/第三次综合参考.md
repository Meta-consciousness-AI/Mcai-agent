## 一、方向清单（按主题归并）

### A. 语义网服务化

1. 上线 SPARQL 查询端点（55%+）：TTL 已发布，但缺查询入口；做完形成「三接入」——MCP 给 Agent、HTTP 给客户端、SPARQL 给学界。
2. 发布推理引擎（OWL 推理），支持自动推导。
3. 把 RDF 从「文件」变成「服务」：可查询接口或在线图谱，不用下载就能查。

### B. MCP 工具补全

4. 补 `cite`（带出处引用）、`provenance`（PROV 溯源）工具（短期 1–2 周）。
5. 更高级 Agent 工具：逻辑推演、多版本比对。
6. 「元意识 Agent 验证套件」：检查回答是否偏离术语定义、是否引用正确节点、是否越权推理。

### C. 工具链化

7. 六步法工具化、流水线化（90%）：输入文本，自动产出术语表、问答、关系图、MCP 服务。

### D. 语料扩展

8. 四语料复现的「语义网化」回灌：把三部公共经典按 v1.2 的 SKOS+PROV+DC 打包 RDF。
9. 横向复制到更多经典：论语、孟子、庄子、金刚经。
10. 复制到其他学说：牛港贝、吕永兴等，做「民间思想知识库集合」。

### E. 多版本异文

11. 把 V1.3 的 `edition_variants` 与 RDF 融合：在图谱中标注异文溯源，让机器识别「帛书本 vs 王弼本」。

### F. 学术接入

12. 学术图谱系统接入演示：Neo4j / Apache Jena / Obsidian 导入 Demo。
13. 接入 TEI、图书馆 Linked Data、数字人文实验室。
14. 学术化与跨语言：发论文，巩固 w3id 命名权。

### G. 渠道

15. 把数据集铺到 AI 开发者真正逛的地方（如 HuggingFace）。
16. 主动做传播与社区运营（承认瓶颈在触达）。

### H. 社区

17. 发起「中文经典古籍语义网」众包开源运动：他做总架构师，别人添砖加瓦。

### I. 规范

18. 发布 V1.3 正式版 + 新增 2–3 个示范案例（庄子、金刚经）。

## 二、共同判断

- 多个 AI 都把「工具链化」列为最高概率（90%）；
- 都把「语义网服务化」列为第二梯队（55%+）；
- 都认为下一步是「降低被使用的门槛」，而不是加内容；
- 都提到触达是瓶颈（GitHub 0 star、真实调用 0）。
