# 工作备忘包

> 30 年长跑的第二大脑。这里放「现在不做、但将来可能要做」的事。
> 每一条都必须有**可观察的触发条件**，否则不收。
> 唯一权威表：[00 总索引](00-总索引-触发条件.md)。

## 分类

| 目录 | 放什么 |
|---|---|
| `00-总索引-触发条件.md` | 所有暂缓事项与触发条件（唯一权威） |
| `01-综合参考/` | 外部 AI 的第一、二、三次综合参考与模板 |
| `02-技术备忘/` | 技术方向明细（语义改写等） |
| `03-渠道备忘/` | 渠道与合作（HF、学术、ctext 等） |
| `04-内容备忘/` | 语料与发布的门槛 |
| `05-项目备忘/` | 暂停的项目（中华经典、实操文） |
| `06-模板/` | 新备忘条目模板 |

## 规则

1. **先查总索引**：任何「这个是不是以后要做」的问题，先看 00 表；
2. **新增条目四件套**：事项、现状、触发条件、明细文件；
3. **触发条件可观察**：数字、事件、明确问句，不写「以后再说」；
4. **触发后转正**：移到 `docs/工作计划.md`，在 00 表标「已启动」；
5. **复检节奏**：每季度 30 分钟过一遍 00 表；每年一次 2 小时全面复检；
6. **不复用旧结论**：条件变了，重新评估，不直接照搬。

## 为什么这样设计

- 30 年里，记忆会丢，文档不会；
- 没有触发条件的备忘，等于没写；
- 分类是为了找得到，索引是为了不遗漏。
