## 使用规则

1. 每次收到新的「综合参考」，先登记到索引，再整理成一份 md；
2. 整理时只记录「方向、原话、判断」，不写情绪与评价；
3. 可马上做的 → 进 `docs/工作计划.md`；
4. 条件未成熟的 → 进 `待条件成熟.md`；
5. 不因为 AI 说了就立项，按 `docs/工作法-反馈驱动.md` 判断。
