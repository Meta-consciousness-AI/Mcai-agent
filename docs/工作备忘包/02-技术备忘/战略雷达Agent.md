# 战略雷达 Agent（T11）

> 目标：把「人工收集意见 + 跟踪行业动态」变成半自动、可持续的机制。
> 状态：暂缓，等触发条件。

## 一、要解决什么

现在是我人工收集各方意见、人工读图整理；未来信息来源会越来越多（AI、专家、平台、论文、竞品），人工会成为瓶颈，也容易漏。

## 二、它要做三件事

1. **收意见**：收集 AI、专家、用户的建议，按统一模板入库；
2. **追动态**：跟踪 MCP 生态、知识图谱、数字人文、竞品发布；
3. **做初筛**：去重、分类、标注「理念 / 可落地 / 需调查」，不代替人判断。

## 三、输出

- 每周一页「信号简报」：新增建议、行业变化、与本项目的关联；
- 每条都带来源、时间、原文链接；
- 直接对接 `工作备忘包/00-总索引-触发条件.md` 的格式。

## 四、分阶段

| 阶段 | 做什么 | 成本 |
|---|---|---|
| 1 | 固定信息源清单 + 统一模板 + 人工整理 | 几乎为零 |
| 2 | 半自动：脚本抓 RSS/搜索/页面，人工审阅 | 1–2 周 |
| 3 | 自动：定时任务 + 摘要 + 分类，人工只做判断 | 需稳定运行环境 |

## 五、约束

- 不订阅付费服务；
- 抓取遵守站点规则；
- 摘要必须可回溯到原文，不许二次编造；
- 判断权在人，不在 Agent。

## 六、触发条件

满足其一即启动：

1. 每月新增参考材料超过 3 份，人工整理耗时超过 4 小时；
2. 需要同时跟踪 5 个以上信息源；
3. 出现「漏看重要动态」的实际损失；
4. 有稳定的定时运行环境（不必依赖本机）。

## 七、第一步（触发后）

1. 列信息源清单（MCP 注册表、Glama、mcprush、Zenodo、arXiv、HuggingFace 镜像、行业公告）；
2. 定模板（来源、时间、摘要、判断、触发条件）；
3. 写半自动脚本，只做抓取与去重，不做判断。
