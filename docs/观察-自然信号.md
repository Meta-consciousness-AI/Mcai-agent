## Bing 收录检查（2026-11-16）

四种查询均无本站结果，`site:` 查询回落到无关页面，判断为**未收录**。

原因：默认域名 `*.tcloudbaseapp.com` 对爬虫不友好（附件头、平台限制），提交 sitemap / IndexNow 也无法让爬虫抓到有效页面。

结论：收录前提是自定义域名 + 备案；在此之前不反复提交。
