## 一、根因与方案
- 根因：Windows 控制台默认 GBK，`print("✅ …")` 写 U+2705 抛 `UnicodeEncodeError`，命令以 1 退出（复现见下）。
- 方案（两条都做）：
  1. **符号 ASCII 化**：`mcai/cli.py`、`pipeline.py`、`server.py`、`toolchain.py` 中输出用的 ✅/❌/📄/⚠️/↳ 改为 `[OK]` / `[FAIL]` / `[SITE]` / `[WARN]` / `->`；中文原样保留。`dashboard.py` 的 ✅/❌ 只写进 HTML 文件、不经控制台，未改。
  2. **入口兜底**：`mcai/cli.py:main()` 首行调用 `_safe_stdio()`，对 stdout/stderr 执行 `reconfigure(errors="replace")`——**只放宽错误处理，不改编码**（避免 GBK 控制台把中文写成乱码），管道/重定向同样生效；Stream 不支持时静默跳过。
