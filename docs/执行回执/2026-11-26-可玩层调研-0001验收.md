## 二、我采纳的三条判断

1. **定位：表达层，不是产品线。** 附二那句"若有人开始算它的 ROI，方案应退回 `0000` 重议"——照办，**列为本项目停止条件之一**。
2. **架构：A（静态单页）。** 且接受"A 是稳态、不是过渡态"：没有机构客户与流量时，一直停在 A 是正确的。
3. **顺序：先写《场景设定三条不能改》，再写第一个场景。** 这一条我从"建议"升级为**硬性前置**：不写不做。理由是它防的正是最重的那个风险——场景反过来定义设定。

## 三、三处收紧（我改的，不是它建议的）

### 1. 删掉"外部会话 ≥30"这条停止线

附一第 4 条说对了：若容器日志清零，这个指标测不出来，小样会产出一个测不出结论的结论。**裁定：第一版不做埋点、不设外部会话门槛。** 验收只看深访三项（完成率 / 复述率 / 回看率，n=8–10）；`src=` 归因照带，但只作观察记录，不作停止线触发。

理由：为一个测不准的指标写代码，是给实验加噪声，不是加证据。

### 2. 预算硬线（填空，即刻生效）

| 项 | 硬线 |
|---|---|
| 现金 | **≤¥1,200**，只允许"≤2 张插画"一种用途；素材包 / 音效 / 引擎授权 / 付费字体一律不批 |
| 自有工时（`0002`） | ≤10 人日 |
| 作者工时 | **≤1 天**（只用于写三条不能改） |
| 编辑工时 | ≤2 天 |
| 日历 | ≤3 周（含缓冲） |
| 超出任一条 | 停工回报，不自行加码 |

**说明**：我 11-26 00:30 给 `0002` 的线是"现金 0 元"。这里改成 ¥1,200，理由只有一条——**美术为 0 会让失败原因无法归因**（分不清是格式不行还是太简陋，实验就白做）。这是对实验有效性的让步，不是对预算的松口：¥1,200 是天花板，默认不花。

### 3. 升级线去掉不可测项

原 §6.5 是"四条同时成立"。改为**两条硬条件**：① 复述率 ≥50%（n≥8 深访）；② **至少 3 个人主动问"还有没有下一个"，且有原话记录**。完成率与回看率仍记录，但不作升级门槛。

## 四、Go / No-Go

**Go：先做小样。**

1. 它买的是"格式是否成立"的知识，成本 ≤10 人日，**失败也有明确结论**（这条最重要——能判死的实验才值得做）；
2. 它是所有媒介的母版（场景库），即使不做游戏也可导成分镜与脚本——**买的是期权，不是产品**；
3. 它能当场暴露需求侧最硬的信号：**如果连 8–10 个愿意坐下来玩 10 分钟的人都找不到，这件事就到此为止**，而这个答案几乎免费。

**不批的理由也留档**：需求无法验证、分发是已知瓶颈、10 人日可投给正式文本。我判 Go 的关键在于——**它不占用"正式文本"那条线**（作者 1 天，不是 1 周），且产物可复用。
