### 4. 四种状态码（含两个成功码）逐条输出

本地 `http.server` 起在 `127.0.0.1`，按路径返回不同状态，`--endpoint` 指过去：

```
200 exit=0   [OK] IndexNow 已接收：status=200 urls=71
202 exit=0   [OK] IndexNow 已接收：status=202 urls=71
403 exit=1   [FAIL] 403 key 校验失败：keyLocation 是否可访问、内容是否与 key 完全一致
422 exit=1   [FAIL] 422 URL 不属于该 host
429 exit=1   [FAIL] 429 请求过快，稍后再试
500 exit=1   [FAIL] 非 2xx：status=500 urls=71
```

403/422/429/500 都会跟 3 行响应正文（stub 给的 `stub body for 403 / second line / third line`），证明正文没被吞。

分批：`len(urls) > 10000` 才分批，每批打印「第 i/N 批：n 条」；本站 71 条，一次请求。

### 6. 真实外网提交未验证

原因：沙箱内 TLS 一律 `SEC_E_NO_CREDENTIALS`（`urllib` 走 schannel，同样是 `AcquireCredentialsHandle failed`），连不上 `api.indexnow.org`。所以 §4 用的是本地 stub 服务器，只验证了请求体、状态码分支与文案；**真实提交留用户窗口**，命令即执行顺序第 3 步。
