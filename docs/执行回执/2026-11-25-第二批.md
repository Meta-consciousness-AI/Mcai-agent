## 一、`Add-Pin` 改了什么

**改前**（原 L146–149）：

```powershell
function Add-Pin([string]$ip) {
    Add-Content -LiteralPath $hostsPath -Value "$ip github.com" -Encoding ASCII
    ipconfig /flushdns | Out-Null
}
```

**改后**（现 L146–160）：

```powershell
function Add-Pin([string]$ip) {
    # hosts 的末行可能没有换行符（2026-11-25 实测：822 字节、末字节 0x74，即
    # `#\t::1             localhost` 后直接结束）。此时 Add-Content 会把新行拼到末行尾部，
    # 变成 `#\t::1             localhost20.233.83.145 github.com`——整行是注释，
    # git 和判据都读不到，等于没固定。所以先补换行，写完再回读确认。
    $bytes = [System.IO.File]::ReadAllBytes($hostsPath)          # L151
    $endsWithNewline = ($bytes.Length -gt 0 -and $bytes[$bytes.Length - 1] -eq 0x0A)   # L152
    $line = "$ip github.com"
    if ($bytes.Length -gt 0 -and -not $endsWithNewline) { $line = "`r`n" + $line }     # L154
    [System.IO.File]::AppendAllText($hostsPath, $line + "`r`n", [System.Text.Encoding]::ASCII)  # L155
    ipconfig /flushdns | Out-Null
    if (-not (Test-HostsPin $ip)) {                              # L157
        throw "hosts 已追加但回读不到 `"$ip github.com`" 这一行，固定未生效（$hostsPath）"    # L158
    }
}
```

改动逐行：

- **L151–152**：新增——先读末字节，判断是否以 `0x0A` 结尾（CRLF 也以 `0A` 结尾，一并覆盖）；
- **L154**：新增——不以换行结尾就先补 `CRLF`；文件为空时不补（避免开头多一个空行）；
- **L155**：把 `Add-Content` 换成 `AppendAllText`，一次写入「（可能的）CRLF + 行 + CRLF」，不再依赖追加语义；
- **L157–158**：新增——写完用 `Test-HostsPin` 回读，读不到直接抛错。

「备份 → 改 → 整体覆盖还原」与「还原留在 `finally`」未动。

## 二、演练前提：末行无换行的 hosts

演练用的临时 hosts 按系统默认文件构造，末行为 `#\t::1             localhost`，**末尾没有换行**：

```
hosts size=167  last10=20 6C 6F 63 61 6C 68 6F 73 74
```

即末尾是 `" localhost"`，最后两个字节是 `73 74`（`st`），**没有 `0D 0A`**。

补充：真实系统 hosts 只读核对（**只读，未写**）——`C:\Windows\System32\drivers\etc\hosts` 822 字节，末 4 字节 `68 6F 73 74`（`host`），`endsWithLF=False`，末行 `#\t::1             localhost`。与 10:28 现场一致，说明新逻辑在真实文件上同样会走「先补 CRLF」分支。

## 七、本次是演练，真实网络的那一次留待用户窗口

**未验证**：真实管理员窗口下 `-ForcePin` 的整链（写系统 hosts → git 经 hosts 连上被固定的 IP → 推送 → 还原）。本次改动只碰 `Add-Pin` 的写入方式、`$touched` 位置和一句文案，但**写系统 hosts 这一步沙箱里做不到**，必须由你在管理员窗口复跑一次确认。

演练的全部替代点（其余代码与生产文件逐行相同）：

1. 权限门 `if (-not $CheckOnly -and -not (Test-Elevated))` → `if ($false)`（沙箱非管理员）；

3. `$hostsPath` → 工作区临时文件（写系统 hosts 需管理员）；
4. `Add-Pin` 内三个钩子：`MCAI_DRILL_OLDPIN`（用改动前的一行 `Add-Content` 造反例）、`MCAI_DRILL_PINFAIL`（模拟写失败）、`MCAI_DRILL_NOPIN`（不写）；
5. `Undo-Pin` 开头 `MCAI_DRILL_RESTORE_FAIL` 钩子（造还原失败）；
6. `git` → 本地假件（只实现 `rev-parse` / `ls-remote` / `push`，第一次 push 返回 1）。
