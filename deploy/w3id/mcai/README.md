# MCAI Knowledge Assets — w3id redirects

Maintainer: Meta-consciousness-AI (https://github.com/Meta-consciousness-AI)

This directory provides persistent identifiers for the MCAI knowledge vocabulary.

- `https://w3id.org/mcai/ontology` — RDF vocabulary (Turtle)
- `https://w3id.org/mcai/scheme` — SKOS concept scheme
- `https://w3id.org/mcai/concept/{slug}` — one concept page
- `https://w3id.org/mcai/document/{doc_id}` — source document fallback
- `https://w3id.org/mcai/category/{hash}` — category fallback

Current targets point to the project site and dataset; targets may change without
changing the identifiers.
